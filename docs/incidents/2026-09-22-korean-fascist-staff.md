# 구국군 참모 운영 F2 구현 기록

작성: 2026-09-22. [상세 명세](../HOK_KOREAN_FASCIST_STAFF_SPEC.md), [2차 확장 계획](../HOK_KOREAN_SECOND_WAVE_PLAN.md).

## 범위와 기준선

사용자의 `AGENTS.md`, `docs` 확인 후 후속 확장 구현 요청에 따라 파시즘 F2 정책 묶음을 추가했다. 시작 브랜치는 `feat/korean-focus-expansion-ai`, 커밋은 `691ffa37740237feddf0b44fc68cfa47b10d76bf`다. 이 커밋 이후 미커밋 상태였던 F1 군수계약 구현을 포함한 **358개**가 실제 작업 기준선이다. 기존 변경을 되돌리거나 F1을 다시 구현하지 않았다.

- 시작 한국 중점 파일 SHA256: `8537c9b8df2ed75acd0f007aa00f8ebefcb80ac597d677eaf6e5c5ed06840a0b`.
- F2 적용 파일 SHA256: `8a721a8739834bac5a0ed30f3d3335ced9ceaf4bc63439b1db8bfe2c14299aa8`.
- 시작 미커밋 파일 31개를 작업용 기준선에 복사하고 해시를 대조했다. 이 중 운영 파일은 17개다.
- 작업 자료: `.local-artifacts/korean-focus-expansion/fascist-staff-20260922/`. 개인 로그·설정·저장 목록과 진단 도구는 이 무시되는 경로에만 보관한다.

대상 설치본은 HOI4 `1.19.3.0.c01a`, Steam build `25205862`다. 런처의 `mod/hearts of korea.mod`는 이 저장소를 가리키며 현재 구성은 HoK 1개와 DLC 36개다. `Korean Language`는 descriptor에 선언돼 있으나 이 실행 구성에서는 활성화되지 않았다. Road to 56은 추가하지 않았다. 게임 원본과 원작 Workshop 사본은 읽기 전용 참고 자료로 사용했다.

시작 시 실제 최신 로그는 F1 delivery-first 즉시 진단 실행(`2cb9`, 1936.1.1.12)이었다. F1 문서에 기록된 진단 없는 `7b9a` 실행과 구분한다. 로그 4개, descriptor·런처 정보·설정·플레이세트 및 기존 저장 13개의 해시를 보존했다. 시작 시 게임 프로세스는 없었고 자동 저장 설정은 `HALFYEAR`였다.

## 구현 결과

중점 **4개**, 국민정신 **2개**, 이미지 **6개**를 추가하여 한국 중점은 **362개**가 됐다. 2차 후보 134개 중 적용은 36개, 나머지 98개는 미확정 설계다. 파시즘 후보 24개 중 F1·F2 8개가 적용됐다. 이번 수치는 구현 중 채택한 설계이며 사용자가 개별 수치를 지정했다고 기록하지 않는다.

`선군주의`에서 참모보직 정비로 진입하고, 작전기획국·야전보고 체계를 병렬로 수행한 뒤 참모업무 규정에서 합류한다. 두 가운데 정책은 모두 수행할 수 있고 마지막에는 둘 다 필요하다. F1 군수계약 완료를 요구하지 않는다. 네 중점은 각 35일, 모두 완료하면 140일이며 기존 부모까지의 기간은 제외한다.

- 참모보직 정비: 육군 경험치 50.
- 작전기획국: 참모업무 체계 I — 계획 수립 속도 +15%, 최대 계획 보정 +10%.
- 야전보고 체계: 전자공학 연구 혜택 100% 1회, 육군 경험치 25.
- 참모업무 규정: 같은 정신을 II로 교체 — 계획 수립 속도 +20%, 최대 계획 보정 +15%. 하위 정신이 이미 없으면 II를 직접 지급한다.

최대 계획은 `max_planning_factor`이며 고정 최대 계획 값인 `max_planning`과 구분한다. 기존 공통 참모 정신·계룡대·독일 장군참모를 제거하거나 자동 지급하지 않는다. 새 정신만 파시즘 정부 상실 시 제거하도록 정의하며 정권 복귀만으로 자동 복원하지 않는다. 신규 결정·범주·DLC 조건은 없다. 기존 결정의 비용·기간·플래그는 바꾸지 않았다.

기존 358개 중점 블록은 원문 그대로 보존했다. 중점 파일 외 기존 미커밋 운영 파일 16개의 해시도 같다. 기존 역사 AI 목록·중점 보상·진행 조건·좌표·offset·지속적 중점 패널·바로가기는 유지했다. 새 중점의 기본 AI 가중치는 2다.

## 배치와 이미지

배치는 `(172,6) → (171,7)/(173,7) → (172,8)`의 3행이다. 첫 기준은 `(169,5)`의 `KOR_prussia_in_the_far_east`이고 새 상대 기준은 모두 참조 전에 선언한다. 전체 범위 `x0~204/y0~24`, 절대 기준 7개를 유지하며 상대 배치는 355개가 됐다.

독립 배치 검토에서 원안 `(175,7)`은 기존 `(176,7)` 이름판과 겹쳐 제외했다. 적용 좌표는 실제 GUI의 96×130 간격·제목판을 바탕으로 한 보수적 사각형 모델에서 신규 겹침 0건이다. 형제의 제목판 사이 여백은 28px, 보수적인 183px 합성 사각형 모델에서는 9px다. 기존 420개·신규 5개 선행선을 직각 경로로 가정한 검사에서 신규 간섭 후보는 없었다. 이는 엔진의 실제 연결선이나 SHOW/HIDE 검증이 아니다.

차콜·갈색 RGB `(70,60,48)`과 금속 테두리를 유지하고 명부·지도·야전무전기·교범 소재를 구분했다. 중점 4개는 100×88, 국민정신 2개는 60×68이며 I·II는 정신 단계에만 표시했다. 기존 DDS 157개는 변경하지 않았다. 10개 스프라이트 및 마스크·광택 경로는 저장소 안의 실제 파일을 참조한다.

## 검증

정적 검사 **84 PASS / 0 FAIL**: 기존 블록·파일 보존, 중점 ID·선행·상대 기준 및 순환, 좌표 명세 일치, 신규 조건·기간·AI, 중괄호·주석, 한영 채널의 한국어 현지화 12키·BOM, 스프라이트·정확한 내부 경로·DDS 크기와 해시를 확인했다. 이미지 담당의 별도 검사에서는 배경 마스크 밖 색·알파 보존과 I·II 배지 외 동일성을 확인했다. 실제 크기 접촉표를 검수했다.

런타임은 설치본 1.19.3에서 아래 네 번을 각각 완전히 새 프로세스로 실행했다. 모든 보상 진단은 1936.01.01.12 안에서 수행했고 기존 F1은 강제 완료하지 않았다.

보상 결과 합계는 **125 PASS / 0 FAIL**이다. 진단에 따른 체크섬 차이를 순정 체크섬이나 멀티플레이 호환성의 증명으로 취급하지 않는다. 연구 보너스 조회는 전자공학 범주가 전에는 없고 이후 존재한다는 사실을 확인하며, 100%·1회는 실제 운영 소스로 대조했다. 연구 한 번을 완료해 보너스를 소모하는 검사는 하지 않았다.

실제 수정치 차이는 I에서 계획 수립 속도 +0.15·최대 계획 보정 +0.10, II에서 +0.20·+0.15였다. 진단이 준비한 공통 참모 II·계룡대·general_staff의 계획 수립 속도 합계 +0.55와 조직적 협동·최대 지휘력·육군 조직력은 보존됐다. 경험치 증가량은 50+25=75였다. 이러한 임의 초기 상태와 강제 완료는 정상 접근, 최종 AND 차단 또는 140일 진행을 입증하지 않는다.

네 실행의 error.log는 모두 128행으로, 선두 벽시계만 제거하면 작업 시작 전 F1 진단과 F1의 진단 없는 실행 로그에 내용·순서까지 일치했다. **신규 오류 0건**이며 기존 오류를 해결했다는 뜻은 아니다. 최종 game.log의 Something went wrong with the Conflict Risk stuff 문구는 작업 시작 전 F1 진단 로그에도 있었다. F1의 진단 없는 game.log에는 없으므로 전체 game.log가 서로 같다고 주장하지 않는다. 이 기존 문구의 원인은 이번 F2 범위에서 조사·수정하지 않았다.

네 실행에서 기존 저장 13개를 각각 백업하고 전후 해시 일치를 확인했다. 설정·플레이세트·동결한 운영 파일 32개도 동일했다. 실행 소유 프로세스만 종료했고 배치한 진단 파일 2개는 해시를 확인한 뒤 제거했다. 최종 검증에는 진단 파일을 배치하지 않았다. 개인 로그·설정·저장이나 진단 스크립트는 Git 대상에 추가하지 않았다.

첫 두 실행 시도는 게임 시작 전에 로컬 PowerShell 실행 정책 및 검증 스크립트의 PowerShell 5.1 JSON 배열 처리 문제로 종료됐다. 시스템 정책을 영구 변경하지 않고 해당 프로세스에서만 검토한 스크립트를 실행했으며 배열 처리를 고쳤다. 이 준비 단계는 보상 검증 결과에 포함하지 않는다.

F1의 68 PASS나 공산 중점의 검증 횟수를 이번 F2에 합산하지 않는다.

Windows 화면 접근은 `computer-use`의 `sky.list_windows()`로 확인했으나 `Computer Use native pipe is unavailable ... 지정된 파일을 찾을 수 없습니다. (os error 2)`로 실패했다. 실제 아이콘·광택·이름판·선행선·초기 및 정치 선택 후 SHOW/HIDE 검수는 미완료다.

정상 35일 중점 진행, 전자공학 연구 혜택 소모, 정부 상실 시 자동 제거, 전투 계획 적용, 장기 AI, 기존 저장 호환성, 다른 DLC·멀티플레이는 즉시 보상 검사로 증명하지 않는다. 기존 F1의 정상 비용 지불·90일 만료·취소 검증도 별도로 남는다.
