## 구현과 영향

[상세 명세](../HOK_KOREAN_COMMUNIST_GOVERNANCE_SPEC.md)에 따라 중점 9개, 국민정신 4개, 기간제 결정 4개를 추가했다. 한국 중점은 **345개**다. 여운형은 기존 전국 협동조합 연합 뒤에 4개, 박헌영은 중공업 종합배정 뒤에 5개를 붙였다. 초안의 부착점 변경은 미적용 후보에만 해당하며 기존 필수 선행을 바꾸지 않는다.

여운형은 정치력 150·기본 안정도 10%p, 전자공학 연구 100% 1회와 노농 협약 I→II를 받는다. 협약은 안정도 10%p·일일 정치력 0.5에서 15%p·0.75로 강화된다. 박헌영은 산업 연구 150% 1회씩 두 번, 정치력 150과 생산계획 I→II를 받는다. 생산 효율 성장 15%를 보존하면서 II에 효율 상한 10%p가 추가된다.

각 노선의 두 사업은 정치력 150만 쓰고 90일 동안 적용된다. 새 네 사업끼리 최대 하나, 종료·취소 후 90일 공통 대기시간이 있으며 정권·경로 상실·내전·항복 때 효과를 회수한다. 기존 경제 사업의 실행 제한과는 별개이므로 기존 사업 하나와 새 사업 하나를 동시에 운영할 수 있다. 이 누적 효과는 이번 설계에 포함되며 명세의 예시 합계와 구분해 검토한다.

신규 국민정신은 기존 경제 정책의 국민정신을 지우지 않는다. 같은 새 계열의 I·II만 교체하고, I이 없으면 II를 직접 지급하는 복구 경로를 둔다. 공산정부 상실로 제거된 정신은 정권 복귀만으로 자동 복구되지 않는다. 이미 완료된 중점의 보상을 소급 지급하지 않는다.

중점은 x75의 y14~17과 x98의 y14~18에 모두 상대좌표로 연결했다. 기존 336개 배치와 전체 범위 x0~204·y0~24, 지속적 중점 패널을 유지한다. 새 AI 기본 가중치는 2이며 기존 민주 역사 AI 계획에는 삽입하지 않았다.

그림은 [허용된 소재와 새 합성·직접 제작 도형](../HOK_KOREAN_COMMUNIST_GOVERNANCE_ICON_CREDITS.md)으로 중점 9개·국민정신 4개를 제작했다. 공산 계열 짙은 적색, 금속 장식, I·II를 유지하고 모든 그림·마스크·오버레이를 프로젝트 내부 상대경로로 연결했다. 기존 광택 오버레이 내부화는 이전 커밋에 이미 적용된 작업이다.

## 런타임 검증과 남은 작업

사용자가 기존 게임을 직접 종료했다고 알린 뒤 프로세스 부재를 확인하고, 네 개의 독립된 새 1936 KOR 게임을 실행했다. 각 실행은 기존 지도자·이전 정책을 진단 초기조건으로 준비하고 이틀 안정화한 다음 새 중점을 강제 완료하고 사업을 활성화했다. 정부 변경 다음 날인 1월 4일에 취소를 확인했다. **이번 새 묶음의 검사 결과는 199 PASS / 0 FAIL**이며, 앞선 첫 10개 149 PASS와는 별도 기록이다.

| 시나리오 | 보존한 기존 선택 | PASS | FAIL | 진단 포함 체크섬 |
|---|---|---:|---:|---|
| 노사협약 이행 | 공동구매 II | 50 | 0 | `4a70` |
| 지역민생 협약 | 자율금융 II | 51 | 0 | `c628` |
| 물자 배정 재조정 | 군수설비 II | 49 | 0 | `e8be` |
| 생산계획 전환 지원 | 현행생산 II | 49 | 0 | `8eca` |

기존 선택 정신이 유지된 상태에서 신규 I→II 교체, 새 정신·사업의 직접 수정치, 사업의 공장 사용량 증가 0, 진행 플래그 설정과 정부 변경 후 해제·공통 대기시간 설정을 확인했다. 자율금융 경로는 새 노농 협약 I을 먼저 제거한 뒤 II를 직접 지급하는 복구 경로도 통과했다. 기존 경제사업의 진행·대기 플래그를 바꾸지 않는 것도 확인했다. 영토·주·수도·공장 변경은 진단에 넣지 않았다.

연구 혜택은 기존 정책을 보상 없이 해금한 초기조건에서 해당 연구 범주가 없음→있음으로 바뀌는 것을 확인했다. 이 검사는 혜택별 실제 사용 횟수·배율이나 박헌영의 두 번째 산업 혜택을 독립적으로 입증하지 않는다. 노사협약의 합계 공장 출력 변화는 안정도의 파생효과도 포함하므로 관찰값으로만 기록하고 순수 결정 보너스 +10%의 별도 assertion으로 세지 않았다.

네 실행의 모드 구성과 보존한 저장파일 목록·크기·수정시각은 전후 같았다. 첫 실행에서 엔진이 `settings.txt`에 `graceful_exit=no`를 추가했으므로 설정 파일 전체가 바이트 동일하다고 주장하지 않는다. 기존 언어·화면·자동저장 등 옵션값은 같았으며 후속 세 실행의 설정 사본은 바이트 동일했다. 설정을 수동 변경하거나 복원하지 않았다. 진단 파일은 각 실행 후 해시를 대조해 제거했다. 원문 로그·fixture·요약은 ignored 작업 폴더에 보존한다.

진단을 제거한 마지막 일반 실행은 **HOI4 1.19.3.0.c01a, 체크섬 `e941`, 일반판 모드 1개·DLC 36개**로 새 1936.1.1.12 싱글플레이 진입을 로그에서 확인했다. 이 실행과 네 진단 실행의 `error.log`는 기존 `0b09` 일반 실행과 시각만 정규화하면 동일한 128개 오류 기록이다. 신규 정책·연구 이름·아이콘·상대 기준 관련 오류나 진단용 dynamic token 경고는 새로 나타나지 않았다. 기존 캐릭터·교리·기술·descriptor 등의 오류가 남아 있으므로 전체 모드에 오류가 없다는 판정은 아니다.

마지막 일반 실행의 설정·모드 구성·저장파일 목록 사본도 전후 동일했다. 검사 전후 관련 생산 파일·이미지 22개의 SHA256이 같고, 임시 진단 파일 두 개와 작업에서 실행한 게임 프로세스는 남아 있지 않다. `git diff --check`, 문서 내부 링크, 별도 정적·런타임 독립 판독을 통과했다. 검증 중 생산 코드를 수정하거나 재균형 조정하지 않았다.

강제 중점 완료·스크립트 사업 활성화는 정상 35일 진행이나 실제 UI 정치력 차감을 입증하지 않는다. 90일 자연 종료·공통 대기 만료·재착수, SHOW/HIDE·광택 상태, 장기 AI, 기존 저장·다른 DLC·멀티플레이도 별도 검증 대상이다. 화면 자동화의 `sky.list_windows()`가 `Computer Use native pipe is unavailable` 오류를 반환하여 화면·실제 버튼 조작 검증은 진행하지 못했다. 대체 임의 UI 입력은 사용하지 않았다.

공산 후보 중 농촌 기술보급 5개와 계획행정 4개는 이번에 구현하지 않았다. 전체 450~470개 목표까지는 105~125개가 남았다. 보병장비 한정 생산량 +10%의 지원 방식·생산비 대안도 별도 미결 상태로 유지한다.

이번 작업에서 커밋·푸시·Workshop 업로드는 수행하지 않았다.
