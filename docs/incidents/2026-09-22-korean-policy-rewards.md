## 검증

정적 검토에서 전체 중점 336개를 변경 직전 사본과 비교했다. 수정한 연구 보상 4개 외의 보상·조건·ID·AI·좌표 차이는 없다. 나머지 두 결정은 원문이 동일하며, 두 언어 파일은 UTF-8 BOM·CRLF와 동일 본문을 유지하고 53개 키가 중복 없이 대응한다. 신규 연구 보너스 이름의 프로젝트·바닐라·Korean Language 충돌은 발견되지 않았다. 후보 JSON의 적용 보상과 현재 좌표 JSON의 소스 해시도 갱신했다.

기존 149 PASS 기록은 조정 전 수치의 검사다. 이번 실행 결과는 별도로 기록하며 과거 통과 결과를 현재 변경의 검증으로 간주하지 않는다. 임시 진단은 같은 정부에서 이틀 안정화 후 중점 보상·정신 교체·사업 효과를 검사하고 정부 변경 다음 날 취소를 관측한다. 영토 이전은 사용하지 않는다.

변경 후 네 개의 독립된 새 1936 KOR 게임에서 다음 결과를 얻었다. 각 실행은 1월 1일 준비 후 1월 3일 보상·사업 효과, 1월 4일 취소를 검사하고 종료했다. 임시 진단 파일이 달라 실행별 체크섬도 다르다.

수정한 두 사업의 `civilian_factory_use` 추가량 0, 유지한 두 사업의 추가량 2를 관측했다. 선택한 국민정신만 I→II로 교체되고, 자율금융 II의 정치력 +1.2·민공 건설 +2%와 현행생산 II의 생산량 +10%가 유지됨을 확인했다. 자율금융 I을 먼저 제거한 뒤 상위 정신을 직접 지급하는 기존 복구 분기도 통과했다. 공산정부 상실 다음 날 국민정신과 사업 효과가 제거되고 공통 대기 플래그가 설정되는 검사도 통과했다.

네 실행의 설정 전후 사본은 같았고 종료 후 임시 진단 파일을 해시 대조해 제거했다. 각 원문 로그와 진단 해시는 `runtime-results/`, 집계는 `runtime-summary.json`에 보존한다.

임시 진단을 제거한 새 일반 실행은 HOI4 1.19.3.0.c01a·체크섬 `0b09`, 일반판 모드 1개·DLC 36개로 1936.1.1.12 싱글플레이 진입을 로그에서 확인했다. 진단 중의 dynamic token 경고 12건은 제거 후 0건이었고, 신규 정책·연구 이름·번역 관련 오류는 발견되지 않았다. 상대 기준 선언 오류도 0건이다. 기존 캐릭터·교리·기술 등의 오류는 남아 있으므로 전체 게임의 오류가 없다는 판정은 아니다.
