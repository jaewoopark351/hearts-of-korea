## 원인 판단과 변경

`CONFIRMED`: 재배치 전 화면에서 긴 선이 다른 가지와 지속적 중점 패널 영역을 통과했다. 신규 민주 모듈과 기존 부모의 기본 세로 간격은 대표 사례에서 14~16이었고, 부모만 조건부로 이동하는 조합이 있었다. 세부 분석과 당시 좌표·행 번호는 배치 설계의 초기 기록에 보존한다.

`STRONGLY_SUPPORTED`: 멀리 떨어진 후속 모듈과 부모·자식 이동의 불일치가 긴 선과 상태별 간섭의 주요 요인이다. 이 설명이 모든 교차의 원인을 입증하지는 않는다. 위치 참조는 진행 선행조건과 별개로 구성했고 기존 AND/OR 및 상호배타 관계를 삭제하지 않았다.

| 실제 변경 파일 | 역할 |
|---|---|
| [korea.txt](../../common/national_focus/korea.txt) | 326개 위치와 상대 기준, 직접 offset 배치, 패널·바로가기 |
| [한국어 탐색 문구](../../localisation/korean/HOK_KOR_expansion_navigation_l_korean.yml) | 기존 3개를 포함한 8개 바로가기 이름 |
| [영문 채널 탐색 문구](../../localisation/english/HOK_KOR_expansion_navigation_l_english.yml) | 프로젝트의 동일 한국어 본문 계약과 대응 키 유지 |

직접 위치 보정은 공화국 공통 `(-8, 0)`, 민주 `(-8, 0)`, 구국군 `(-25, 0)`, 황실 `(-39, 0)`의 네 기준에 남겼다. 네 보정의 기존 조건·토큰은 그대로이며 공산 진입에 새 보정을 추가하지 않았다. 공화국 공통의 OR 조건과 민주 진입의 단일 조건을 혼동하지 않도록 서로 독립된 절대 기준을 사용했다.

런타임에서 초기 만주 유전 `(48, 31)`의 이름판을 다문화 수용·문화 동화정책의 상호배타 선이 가로지르는 모습을 관측했다. 유전을 만주 계획 기준 상대 `(4, 4)`, 기본 절대 `(52, 32)`로 옮겼다. 황실은 기준점을 x550에서 x570으로 옮겨 49개 내부 상대 배치를 유지한 채 구역을 오른쪽으로 20 이동했다. SHOW 실행에서 최종 유전 이름판이 상호배타선 및 x48 합류 줄기와 떨어진 모습을 확인했다. x570으로 옮긴 황실의 진입·후속 정렬도 확인했다. 황실 이동 뒤의 HIDE 전환은 다시 실행하지 않았으므로 최초 HIDE 관측과 정적 상속 대조를 구분한다.

바로가기의 `scroll_wheel_factor = 0.65`에서도 아시아 연합을 연속 클릭하면 목표가 화면 하단에 걸리는 현상이 재현됐다. 만주·아시아 연합 두 개의 값을 생략한 SHOW 비교 실행에서도 첫 이동은 목표 아이콘 상단이 잘리고 반복 이동은 화면 하단에 걸렸다. 생략으로 개선되지 않아 최종 8개 모두 `0.65`로 복원했다. 현재 수동 스크롤이 필요한 알려진 한계이며 원인은 `UNPROVEN`이다. 근거 없는 카메라 offset 키나 별도 GUI 기능은 추가하지 않았다.

## 첫 HIDE 실행 관측과 로그

첫 HIDE 실행은 `043BC…F8113FD` / 체크섬 `9246`을 로드한 한국 1936 새 게임이다. 자연 초기 상태와 임시 수동 결정으로 전환한 공화국·민주·구국군·황실·공산 상태를 일시정지 상태에서 관측했다. 선택한 노선이 남는 표시와 상대 자식의 정렬을 확인했고, 상태 전환 중 국민정신·정치력·안정도 보상이 바뀌지 않는 모습을 확인했다. 이는 중점 보상이나 정상 기간 경과를 시험한 것이 아니다.

진단은 자동 실행이 없는 결정 분류 1개·결정 6개·한국어 진단 문구로 구성했다. 로그에는 실제 클릭한 다섯 상태가 각각 한 번 기록됐고 초기 상태는 자연 시작 화면이므로 INITIAL 클릭 로그가 없다. 임시 파일 3개는 아래 목록이며, SHOW 검수를 마친 뒤 최초 해시와 일치하는지 확인하고 제거했다. 이후 전체 재시작한 `d00f` 실행에는 진단 정의와 로그 표식이 없다.

- `common/decisions/categories/zz_HOK_KOR_layout_test.txt`
- `common/decisions/zz_HOK_KOR_layout_test.txt`
- `localisation/korean/zz_HOK_KOR_layout_test_l_korean.yml`

`after-hide-log-comparison.json`은 보존된 기준선과 첫 HIDE 로그를 비교한다. 정규화는 선두 실제 시각과 `common/national_focus/korea.txt`에 붙은 소스 행 번호만 치환하며 게임 날짜·메시지·객체 ID·엔진 소스 행과 발생 횟수는 유지한다. 다른 작업의 정규화 고유 개수와 직접 비교하지 않는다.

추가 GUI 경고는 싱글플레이 시작 전 게임 설정 화면 시점에 발생했다. 이번 수정 파일이나 focus/fixture ID를 가리키지 않고 저장소에 해당 GUI 덮어쓰기도 없지만, 원인은 `UNPROVEN`이다. 이 기준선에 없었던 경고를 기존 경고라고 단정하거나 전체 신규 오류 0이라고 보고하지 않는다. 기존 `cl_tech` 경고는 korea.txt 행 번호만 이동했고 발생 횟수는 같다.

## SHOW 및 무진단 최종 실행

SHOW 비교 실행은 초기 상태와 민주 선택 상태를 관측했다. 민주 중점의 완료 표시 이후에도 황실을 포함한 다른 분기와 바로가기가 남았다. 만주 유전 `(52, 32)`에서 확인했던 이름판 관통이 해소됐고, 지속적 중점 패널 `(200, 3400)`의 주변에 다른 중점이나 선이 없는 구간을 확인했다. 해당 패널 사진은 왼쪽 일부가 화면 밖에 있어 전체 프레임의 표시를 입증하지 않는다. SHOW의 나머지 네 선택 상태를 실제로 실행했다고 주장하지 않는다.

최종 실행은 진단 파일 없이 `AA58…` / `d00f`를 전체 재시작한 한국 1936 새 게임이다. 초기 지도·정치 상태, 중점창 열기, 8개 한글 바로가기 표시와 산업 구역 이동·축소가 작동했다. `1936.01.01.12`에 일시정지한 상태로 검수했으며 보상 실행·시간 진행·저장/불러오기 시험은 하지 않았다. 테스트 세이브를 쓰지 않았고 완료 시점에는 산업 중점 화면을 열어 둔다.

SHOW 로그는 HIDE 로그와 정규화 오류 종류 및 발생 횟수가 같았다. 최종 무진단 실행의 로그 대조는 별도 `final-clean-log-comparison.json`에 기록했다. 기준선 130행/59종에서 최종 128행/58종으로, 신규 오류 서명과 기존 서명의 발생 증가가 모두 0이었다. 감소한 2행은 기준선 종료 시의 random.log 이름 변경 경고이며 수정 효과로 해석하지 않는다. 앞선 두 실행의 난이도 설정 GUI 경고도 최종 스냅샷에는 없었다. setup/game/error/system 모두 진단 접두사와 임시 결정 등록·실행 기록이 없었다.

## Git과 배포 상태

기존 작업 트리 변경을 보존한 채 파일을 수정·추가했다. 문서에는 최종 좌표표·연결 JSON·검증 기록을 추가하고 관련 계획과 README의 상태를 갱신했다. 이전 확장 incident에는 이 후속 작업의 링크만 추가했다. 커밋·푸시·브랜치 변경·배포·Workshop 변경은 수행하지 않았다. 원작 ID·문구·크레딧은 유지하며 배치 변경은 별도 후속 작업으로 기록한다.
