## 범위와 기준선

사용자는 첫 재배치가 지나치게 넓다며 중점을 가깝게 배치하되 반드시 겹치지 않도록 요청했다. 기존 326개 중점과 게임 진행은 유지하고 위치·조건부 위치 보정·지속적 중점 패널만 수정했다. 중점 추가·삭제와 기간·보상·선행·배타·표시 조건·AI 변경은 포함하지 않는다.

- Git: `main`, `525aae3886becfdf583372dc0caec77cef605ee5`. 기존 확장·의용군 변경과 미추적 문서가 있는 작업 트리에서 시작했으며 보존했다. 이번 작업은 커밋·푸시·업로드를 하지 않았다.
- 설치본: `Operation Postern v1.19.3.0.c01a`, Steam build `25205862`. 현재 설치본의 일본 중점 상대배치와 중점 GUI/GFX를 참조했다. 1.19.2 실행 결과는 아니다.
- 구성: 로컬 HoK가 저장소를 직접 참조하는 launcher 모드. 선언된 Korean Language 의존성과 `l_korean` 설정은 유지했다. 실제 활성 모드 목록과 의존 선언은 구분한다. descriptor·launcher·Workshop·기본 게임은 수정하지 않았다.
- 화면: 1600×900, GUI 배율 1. 주로 트리 배율 0.65, 전체 폭 확인에 0.585/0.5265/0.47385를 사용했다.
- 실행: 이전 게임을 종료하고 수정 후 전체 재시작. 최종 체크섬 `27bf`, 한국 1936 새 게임을 `1936.01.01.12`에 일시정지한 상태로 검수했다. 기존 저장 파일을 덮어쓰거나 중점을 완료하지 않았다.

## 로그와 최종 파일 점검

압축 전후의 error/game/setup/system 로그를 별도 보존했다. 두 error.log는 각각 128행·고유 58종이다. 선두 시각만 제외하면 기존 cl_tech 경고의 korea.txt 위치가 2197행에서 2264행으로 이동한 차이 1개가 나왔다. 이 파일의 행 번호까지 별도로 정규화하면 신규 오류·제거 오류·횟수 증가 모두 0이다. 원본 로그도 남겨 정규화로 숨겨진 차이를 추적할 수 있게 했다. 기존 오류가 없어졌다는 의미는 아니다.

system.log에서 1.19.3/27bf, DLC 36개·활성 로컬 HoK 1개를 확인했다. 배치 진단 파일과 로그 표식은 없으며 최종 production 해시는 위 기록과 일치한다.

Git HEAD 기준 diff 공백 검사는 앞선 작업에서 남은 탭 공백을 보고한다. 이번 AA58 기준선과 적용본의 직접 비교에서는 추가 공백 경고가 없으며 후행 공백을 가진 줄 수는 전후 603개로 같다. 관련 없는 전체 포맷 정리는 하지 않았다. Git 상태에는 기존 작업 변경과 이번 배치·문서 수정이 함께 남아 있으며 커밋·푸시는 하지 않았다.

## 남은 한계

- 만주 바로가기는 목표 중점이 화면 하단에 걸릴 수 있다. 수동 스크롤로 15개 전부를 확인했다. 선·중점 겹침과는 별개인 기존 탐색 문제이며 이번에 해결됐다고 하지 않는다.
- 현재 압축본에서 이념 선택 후 HIDE 전환과 SHOW 규칙을 다시 실행하지 않았다. 위치 불변의 정적 근거와 초기 화면 검증으로 범위를 구분한다.
- 검증한 화면 크기·배율 외의 임의 UI 모드·폰트 변경, 하이라이트 효과는 별도 범위다. 1939 북마크, 장기 AI 진행, 기존 저장 호환, 멀티플레이는 이번 위치 수정의 검증 대상으로 실행하지 않았다.
