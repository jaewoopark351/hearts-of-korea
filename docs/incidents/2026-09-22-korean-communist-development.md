# 공산주의 농촌 기술보급·계획행정 구현

> 후속 변경: 사용자가 긴 직렬 배치를 지적하여 [정책 묶음 병렬화](2026-09-22-korean-communist-parallel.md)를 적용했다. 아래 345개 좌표 보존·직렬 위치·준비된 206항목 진단은 병렬화 전 기록이다. 현재 부모·좌표·결정 범주 조건과 검증 상태는 병렬화 기록을 따른다.

2026-09-22. [상세 명세](../HOK_KOREAN_COMMUNIST_DEVELOPMENT_SPEC.md)에 따라 남은 공산 Y3·P3 후보 9개를 구현한다. 의도적인 후속 콘텐츠 개발이며, 기존 중점 보상 조정이나 다른 정치 경로 확장은 이번 묶음에 포함하지 않는다.

## 기준선

- 브랜치 `feat/korean-focus-expansion-ai`, 시작 커밋 `b300b4090b4a779878332c7ec463170bbe16f4d8`. 시작 당시 작업 트리는 깨끗했다.
- 시작 중점 345개. 이번 9개를 더해 354개, 2차 공산 확장은 여운형·박헌영 각 14개씩 28개다. 전체 목표 450~470개까지 96~116개가 남는다.
- 시작 시 사용자 게임이 실행 중이었다. 보존한 로그는 HOI4 1.19.3.0.c01a, 체크섬 `e941`, DLC 36개와 일반판 모드 1개를 기록한다. 이는 이번 변경 이후 실행 결과가 아니다.
- launcher의 `mod/hearts of korea.mod`는 프로젝트를 직접 가리킨다. 활성 모드 목록을 변경하지 않았으며 Road to 56 구성으로 전환하지 않는다. descriptor의 필수 Korean Language 선언과 현재 비활성 상태는 이전 기준선과 같다. 플레이세트 표시 이름은 확인하지 않았다.
- 실행 중 로그·설정은 ignored 경로 `.local-artifacts/korean-focus-expansion/communist-development-20260922/baseline/`에 보존했다. 기존 사용자 게임·세이브·영토·설정을 변경하지 않는다.

## 변경 내용과 보존

여운형은 노농 협약 정착 뒤에 농촌 공동업무 조사·조합 기술상담소·작업장 기술회보·공동업무 회계 공개·전국 조합 기술보급망을 연결한다. 산업 150%·전자 100% 연구 혜택 각각 1회, 정치력 150, 연구 속도와 기반시설 건설을 강화하는 조합 기술보급 I→II를 받는다.

박헌영은 국가 생산계획 조정 뒤에 국가계획 사무국·지방계획 연락소·현장 기술대표단·계획실적 검토회의를 연결한다. 정치력 150, 산업 150% 연구 혜택 1회, 생산 효율 유지와 새 생산선 시작 효율을 강화하는 계획행정 I→II를 받는다. 유지 보정의 정확한 설치판 키는 `line_change_production_efficiency_factor`다. 새 효과를 기존 효율 성장·상한이나 현재 생산선의 즉시 효율 상승으로 해석하지 않는다.

정치력 150·민공 점유 0·90일 지속의 신규 사업 4개를 기존 후속 내정 범주에 추가한다. 기존 4개와 새 4개가 활성 플래그·종료 또는 취소 후 90일 대기를 공유하여 같은 범주에서 최대 하나만 실행한다. 별도 경제정책 범주의 사업 하나를 병행하는 기존 구조는 유지한다. 상호 배제되는 사업을 합산하거나 세 번째 동시 실행 슬롯을 만들지 않는다.

새 정신은 기존 경제·내정 정신을 지우지 않고 같은 신규 계열의 I만 II로 교체한다. I이 없을 때 II를 직접 지급하는 경로와 공산정부 상실 시 제거 조건을 포함한다. 정권 복귀만으로 제거된 정신을 자동 재지급하지 않는다.

## 정적 검증

- 354개 중점 ID가 고유하며, 기존 345개 focus 블록과 해석 좌표가 작업 전과 동일하다. 선행·배타·상대 기준의 참조와 상대 기준의 선행 선언 순서를 확인했다.
- 새 좌표는 여운형 (75,18~22), 박헌영 (98,19~22)다. 기존 중심점과 중복 없이 전체 x0~204·y0~24를 유지한다. 직전 부모 기준 (0,1) 연결이며 기존 offset·패널·바로가기를 바꾸지 않는다.
- 기존 후속 내정 4개 사업은 원문을 보존하고 같은 파일 안에 새 4개만 추가했다. 범주 정의·기존 국민정신·기존 현지화는 수정하지 않는다.
- 양쪽 새 현지화는 34개 대응 키, 기존 계약에 따른 한국어 본문, UTF-8 BOM·CRLF와 동일 기여 주석을 사용한다.
- 중점 9개·정신 4개·결정 4개의 DDS 17개와 스프라이트 26개를 통합했다. 결정은 전용 32×32이며 기존 51×40 범주 이미지를 유지한다. 일반·정신·결정·광택에서 참조하는 서로 다른 이미지 경로 18개(공유 광택 1개 포함)가 모두 프로젝트 내부에 존재하고, 새 스프라이트 이름은 유일하다. DDS 크기·알파·해시·실제 크기 접촉표를 확인했다. 기존 DDS 131개는 이미지 담당자의 전후 해시 대조에서 동일하다. [아트 출처](../HOK_KOREAN_COMMUNIST_DEVELOPMENT_ICON_CREDITS.md)와 [매니페스트](../data/HOK_KOREAN_COMMUNIST_DEVELOPMENT_ICON_MANIFEST.json)를 따른다.
- 정적 괄호·인용문·현지화·참조 검사와 `git diff --check`가 통과했다. 세부 결과는 ignored 작업 폴더의 `static-structure.json`, `localisation-structure.json`, `asset-integration.json` 및 별도 이미지 검증 기록에 남긴다. 이 결과는 엔진 로딩·실제 UI 표시 검증을 대신하지 않는다.

## 런타임 검증

현재 새 코드의 런타임 검증은 **사용자 세션 종료와 자동저장 임시 변경 승인 대기**다. 앞선 첫 경제정책의 149 PASS 및 후속 내정의 199 PASS는 이번 9개·4사업의 결과가 아니다. 별도 새 게임 2개에서 새 보상·단계 승계·기존 선택 보존, 첫 사업의 90일 자연 종료·공통 대기 만료·재착수와 정권 변경 취소, 두 번째 사업의 단기 효과를 확인하도록 진단을 준비했다. 206개 assertion은 실행 예정 개수이며 PASS 개수가 아니다.

각 시나리오는 약 187게임일을 진행한다. 현재 사용자 설정의 `autosave="HALFYEAR"`와 기존 자동저장 파일을 보호하기 위해 승인 전 게임을 종료하거나 설정을 바꾸지 않는다. 승인 후에는 설정·자동저장을 백업하고 자동저장만 임시 해제하며, 검사 후 설정을 복원하고 저장 파일 목록·해시를 대조한다. 진단은 새 게임에 한정하고 영토·공장·승패·저장 명령을 포함하지 않는다. 임시 파일의 해시를 대조해 제거하고, 생산 코드 26개 파일의 고정 해시를 확인하도록 실행 절차를 준비했다.

이번에도 화면 도구의 `sky.list_windows()`는 `Computer Use native pipe is unavailable`을 반환했다. 화면·실제 버튼 검증과 스크립트 검사를 구분한다. 스크립트 강제 완료·사업 활성화는 정상 35일 진행·실제 정치력 지불·연구 혜택 소모·장비 전환 결과·생산선 신설 결과를 입증하지 않는다. SHOW/HIDE·광택·장기 AI·기존 저장·다른 DLC·멀티플레이는 실제 확인 범위를 따로 기록한다.
