# Hearts of Korea 개발 자료 보관 안내

기록일: 2026-11-05. 이 문서는 외부로 보관한 개발 자료의 위치, 과거 경로의 대응 관계와 후속 이미지 작업의 자료 확인 절차를 기록한다. 새 테스트·중간 산출물은 `C:\hoi\test\<작업 또는 실행 ID>\`에 저장한다. 작업 권한과 공통 보존 규칙은 [AGENTS.md](../AGENTS.md)를 따른다.

## 1. 실제 보관 위치

이전 위치는 `C:\hoi\hearts_of_korea\.local-artifacts\`다. 2026-11-05에 외부로 이동했으며, 새 출력용으로 이 디렉터리를 다시 만들지 않는다.

보관 기준 경로: `C:\hoi\test\archive-local-artifacts-20261105\`

아래 경로는 모두 위 기준 경로에 상대적이다.

| 경로 | 용도 |
|---|---|
| `original\.local-artifacts\` | 이동한 원본 자료. 과거 이미지 원본·프롬프트·미리보기·가공 레시피·테스트 증거를 찾을 때 우선 참조 |
| `.local-artifacts\` | 별도로 복사하고 해시를 대조한 추가 보존 사본 |
| `archive-record.json` | 이전·이후 경로, 이동 방식, 검증 결과와 시각 |
| `source-manifest.json` | 파일별 상대 경로·바이트 크기·SHA-256·기존 생성 및 수정 시각 |
| `source-directories.json` | 기존 상대 디렉터리 구조 |

원본의 전체 경로는 `C:\hoi\test\archive-local-artifacts-20261105\original\.local-artifacts\`다. 기본 자료 탐색은 이 경로를 사용하고 추가 사본과 구분한다. 보관 자료와 기록 파일은 일반 개발 중 읽기 전용 참고자료로 취급한다. 이는 현재 운영체제의 읽기 전용 속성이나 ACL을 설정했다는 뜻이 아니다. 이 문서 자체는 보관 자료의 수정·삭제·추가 이동이나 스크립트 실행을 허가하지 않는다.

위 수량과 용량은 자료 트리 한 벌의 값이다. 추가 사본과 보관 안내용 JSON 파일들의 크기를 합친 값이 아니다. 이동한 원본과 추가 보존 사본 모두 보관 전 manifest와 대조했다. 위 결과는 당시 수행한 검증 기록이며, 후속 작업에서 파일을 다시 검증했다는 뜻으로 사용하지 않는다.

원본 삭제 명령은 자동 정책 검토에서 `blocked by policy`로 차단되어 실행되지 않았다. 이후 원본 폴더를 외부로 직접 이동하고 이미 검증한 사본도 보존하는 방식으로 마무리했다. 자세한 완료 방식은 `archive-record.json`에 남아 있다.

## 3. 과거 경로를 찾는 방법

과거 문서·manifest·스크립트에 다음과 같은 경로가 있으면 `.local-artifacts` 아래의 상대 경로를 그대로 유지해 원본 보관 경로에서 찾는다.

| 과거 표기 | 현재 해석 |
|---|---|
| `.local-artifacts/<상대 경로>` | `C:\hoi\test\archive-local-artifacts-20261105\original\.local-artifacts\<상대 경로>` |
| `<PROJECT>/.local-artifacts/<상대 경로>` | 위와 동일 |
| `C:\hoi\hearts_of_korea\.local-artifacts\<상대 경로>` | 위와 동일 |

파일명 대소문자와 남은 상대 경로를 보존한다. 과거 기록의 경로는 일괄 치환하지 않고 이 대응표를 통해 해석한다.

필요한 파일이 원본 보관 위치에 없으면 추가 보존 사본과 `source-manifest.json`을 확인한다. 누락이나 해시 충돌은 경로와 함께 보고한다. 확인되지 않은 원본을 찾았다고 주장하거나 출처를 지어내지 않는다. 원본을 임의로 대체·재생성한 뒤 과거 자료인 것처럼 취급하지 않는다. 사용자가 별도로 승인한 신규 이미지 제작은 해당 작업의 범위와 출처 기록을 따른다.

## 4. 이미지 제작·수정 전 확인 순서

이미지 작업이 승인된 경우 다음 순서로 자료를 확인한다.

1. 현재 저장소의 완성 이미지, GFX·sprite 연결, 관련 명세·크레딧·manifest를 읽는다. 필요한 원본 이미지·프롬프트·합성 레시피·원출처·기록된 해시는 위 경로 대응표를 이용해 찾는다. 대화 기억 대신 실제 파일로 작업 기준을 확인한다.
2. 중간 출력은 새 `C:\hoi\test\<새 작업 또는 실행 ID>\`에서 만든다. 필요한 과거 입력만 새 작업 폴더에 복사하고 원래 보관 위치를 기록한다. 두 보관 사본을 작업 폴더로 사용하거나 덮어쓰지 않는다.
3. 과거 스크립트를 재사용하기 전에 내부에 고정된 입력·출력·보고서·미리보기·백업 경로를 읽는다. 과거 입력은 대응표로 찾고 새 출력은 현재 작업의 외부 경로로 설정한다. 저장소의 옛 `.local-artifacts`, 보관 원본·사본 또는 업로드 패키지에 출력하는 스크립트를 그대로 실행하지 않는다. 레시피를 읽는 행위는 실행이나 추가 이미지 변경을 허가하지 않는다.
4. 승인 범위의 완성된 런타임 이미지와 프로젝트 소유 GFX·상대 참조를 저장소에 통합한다. 관련 크레딧과 manifest에는 실제 출처·선택한 입력·제작 또는 가공 방법·최종 해시·새 외부 작업 경로를 기록한다. 원작자, 사용 조건, 프로젝트 내부 이미지 보관과 상대 참조 규칙을 유지한다.

이 안내는 과거 자료 재사용을 돕는 개발 문서다. Workshop 배포 허용 목록에 자동으로 포함되는 파일이나 이미지·게임 코드 변경 권한이 아니다.

## 5. 위치 변경 시 갱신

승인된 작업으로 자료 위치가 바뀌면 이 문서의 이전·이후 경로, 원본·추가 사본 구분, manifest 위치, 경로 대응표와 실제 검증 결과를 함께 갱신한다. 기존 검증 이력과 새 검증을 구분하고 과거 기록을 현재 상태처럼 덮어쓰지 않는다. 이 문서 자체의 위치를 바꾸면 `AGENTS.md`의 상대 링크와 필수 열람 조건도 함께 갱신한다.
