## 1. 현재 보관 위치와 자료 역할

현재 보관 기준 경로: `C:\hoi\test\archive-local-artifacts-20261106\`

내용 보존 기준본의 전체 경로는 `C:\hoi\test\archive-local-artifacts-20261106\original\.local-artifacts\`다. `original`이라는 디렉터리 이름은 기존 자료의 보관 역할을 뜻하며, 실제 수행 방식은 폴더 직접 이동이 아니라 파일별 복사·검증 후 저장소 원본 제거다. 이번 작업에서는 별도의 추가 보존 사본을 만들지 않았다.

보관 자료와 기록 파일은 일반 개발 중 읽기 전용 참고자료로 취급한다. 이는 현재 운영체제의 읽기 전용 속성이나 ACL을 설정했다는 뜻이 아니다. 이 문서 자체는 보관 자료의 수정·삭제·추가 이동이나 스크립트 실행을 허가하지 않는다.

## 3. 과거 경로를 찾는 방법

과거 문서·manifest·스크립트에 다음과 같은 경로가 있으면 `.local-artifacts` 아래의 상대 경로를 그대로 유지해 현재 내용 보존 기준본에서 찾는다.

| 과거 표기 | 현재 해석 |
|---|---|
| `.local-artifacts/<상대 경로>` | `C:\hoi\test\archive-local-artifacts-20261106\original\.local-artifacts\<상대 경로>` |
| `<PROJECT>/.local-artifacts/<상대 경로>` | 위와 동일 |
| `C:\hoi\hearts_of_korea\.local-artifacts\<상대 경로>` | 위와 동일 |
| `C:\hoi\test\archive-local-artifacts-20261105\original\.local-artifacts\<상대 경로>` | 위와 동일한 상대 경로를 현재 기준본에서 확인 |
| `C:\hoi\test\archive-local-artifacts-20261105\.local-artifacts\<상대 경로>` | 위와 동일한 상대 경로를 현재 기준본에서 확인 |

파일명 대소문자와 남은 상대 경로를 보존한다. 과거 기록의 경로는 일괄 치환하지 않고 이 대응표를 통해 해석한다. 20261105 경로의 대응은 과거 참조를 현재 보관본에서 찾기 위한 해석 규칙이며, 확인되지 않은 과거 외부 보관본 자체를 이동·복구했다는 뜻이 아니다.

필요한 파일이 현재 기준본에 없으면 `source-manifest.json`과 `source-directories.json`을 확인하고 누락이나 해시 불일치를 경로와 함께 보고한다. 이번 작업에서 만들지 않은 추가 사본이 존재한다고 가정하지 않는다. 확인되지 않은 원본을 찾았다고 주장하거나 출처를 지어내지 않는다. 원본을 임의로 대체·재생성한 뒤 과거 자료인 것처럼 취급하지 않는다. 사용자가 별도로 승인한 신규 이미지 제작은 해당 작업의 범위와 출처 기록을 따른다.

## 4. 이미지 제작·수정 전 확인 순서

이미지 작업이 승인된 경우 다음 순서로 자료를 확인한다.

1. 현재 저장소의 완성 이미지, GFX·sprite 연결, 관련 명세·크레딧·manifest를 읽는다. 필요한 원본 이미지·프롬프트·합성 레시피·원출처·기록된 해시는 위 경로 대응표를 이용해 찾는다. 대화 기억 대신 실제 파일로 작업 기준을 확인한다.
2. 중간 출력은 새 `C:\hoi\test\<새 작업 또는 실행 ID>\`에서 만든다. 필요한 과거 입력만 새 작업 폴더에 복사하고 원래 보관 위치를 기록한다. 보관 기준본을 작업 폴더로 사용하거나 덮어쓰지 않는다.
3. 과거 스크립트의 원문은 보관본에서 유지한다. 재사용이 승인된 경우 필요한 스크립트를 새 외부 작업 폴더에 복사하고, 복사본 내부에 고정된 입력·출력·보고서·미리보기·백업 경로를 읽어 조정한다. 과거 입력은 대응표로 찾고 새 출력은 현재 작업의 외부 경로로 설정한다. 저장소의 옛 `.local-artifacts`, 보관 기준본 또는 업로드 패키지에 출력하는 스크립트를 그대로 실행하지 않는다. 레시피를 읽는 행위는 실행이나 추가 이미지 변경을 허가하지 않는다.
4. 승인 범위의 완성된 런타임 이미지와 프로젝트 소유 GFX·상대 참조를 저장소에 통합한다. 관련 크레딧과 manifest에는 실제 출처·선택한 입력·제작 또는 가공 방법·최종 해시·새 외부 작업 경로를 기록한다. 원작자, 사용 조건, 프로젝트 내부 이미지 보관과 상대 참조 규칙을 유지한다.

이 안내는 과거 자료 재사용을 돕는 개발 문서다. Workshop 배포 허용 목록에 자동으로 포함되는 파일이나 이미지·게임 코드 변경 권한이 아니다.

## 5. 위치 변경 시 갱신

승인된 작업으로 자료 위치가 바뀌면 이 문서의 이전·이후 경로, 원본·보관 기준본·추가 사본의 실제 구분, manifest 위치, 경로 대응표와 실제 검증 결과를 함께 갱신한다. 기존 검증 이력과 새 검증을 구분하고 과거 기록을 현재 상태처럼 덮어쓰지 않는다. 이 문서 자체의 위치를 바꾸면 `AGENTS.md`의 상대 링크와 필수 열람 조건도 함께 갱신한다.
