# 한국 중점 2차 확장 — 전체 구성과 첫 정책 묶음

작성: 2026-09-22. 대상: 설치본 HOI4 1.19.3. 의도적인 후속 콘텐츠 개발이며 호환성 복구와 구분한다.

**현재 적용: 기존 326개 + 공산 경제정책 10개 + 공산 후속 내정 9개 + 기술보급·계획행정 9개 = 354개.** 여운형·박헌영에 각각 신규 14개씩 총 28개를 구현했다. 첫 정책 묶음은 각 5개이며, 각각 한 쌍의 상호배타 선택 때문에 한 경로에서는 해당 묶음의 4개를 완료한다. 현재는 각 경제정책 말단에서 후속 내정과 기술보급·계획행정이 병렬로 갈라진다. 두 후속 묶음은 상호배타가 아니며 모두 완료할 수 있다. 2차 확장 누계는 국민정신 16개와 기간제 사업 12개다. 전체 2차 확장 및 정상 플레이 검증이 완료된 상태는 아니다. 이전 [후속 내정 명세](HOK_KOREAN_COMMUNIST_GOVERNANCE_SPEC.md)와 이번 [기술보급·계획행정 명세](HOK_KOREAN_COMMUNIST_DEVELOPMENT_SPEC.md), 각 작업 기록의 검증 범위를 구분한다.

## 파시즘·비동맹 후속 가지의 설계 기준

2026-09-22 사용자 요청: 공산 후속 중점에서 발생한 긴 일자 구조가 파시즘·비동맹 확장에 반복되지 않도록 한다. 독립적인 정책 묶음을 직전 묶음 말단에 연달아 붙이지 않고, 적절한 진입점 아래에 병렬로 배치한다. [배치 계획 4.6절](HOK_KOREAN_FOCUS_LAYOUT_PLAN.md#46-후속-정치-확장의-긴-직렬-가지-방지)과 AGENTS.md를 구현 전 기준으로 사용한다.

한 묶음은 대체로 3~5개를 출발점으로 검토한다. 긴 직렬 연쇄가 필요하면 이유를 적고, 단순히 x좌표만 바꾼 지그재그 구조로 대체하지 않는다. 해당 정치 경로 안에서 독립된 병렬 묶음은 원칙적으로 모두 완료할 수 있으며, 기존 입헌·전제 등의 배타 경로를 서로 동시에 열거나 배치용 상호배타를 새로 만들지 않는다.

각 상세 명세에는 진입 조건·필수 선행과 배치 기준의 구분, 최장 필수 연쇄와 실제 행 수, 폭·높이·인접 가지 여백, 주요 보상·결정의 최초 도달 시점과 전체 소요 시간을 기록한다. 어느 묶음을 먼저 진행해도 해당 결정 범주·개별 사업·정신 승계가 작동하는지와 필요한 차단 조건을 함께 설계한다. 보상·기간·기존 경로를 임의로 바꾸지 않고, 선행 변경이 필요한 경우 해당 구현의 의도적인 진행 변경으로 명시한다.

이번 요청은 문서화다. 위 노선의 코드는 아직 추가·재배치하지 않았으며 후보 데이터와 적용 개수도 바꾸지 않는다. 공산 병렬화의 정적 결과나 이전 게임 검증을 이 노선들의 검증 결과로 사용하지 않는다.

## 첫 두 묶음의 구현 계약

- [첫 10개 명세](HOK_KOREAN_SECOND_WAVE_FIRST_10_SPEC.md)의 ID·조건·보상만 적용한다. 기존 중점의 필수 선행, 보상, 기간, AI 가중치는 바꾸지 않는다.
- 여운형은 기존 `KOR_rural_support_plan`, 박헌영은 `KOR_heavy_industry_concentration`에서 옆가지로 시작한다. 공산정부·내전 없음·해당 기존 지도자 선택 완료를 요구한다.
- 양쪽 정책은 선택한 국민정신만 I→II로 교체한다. 하위 정신이 이미 제거됐다면 선택된 상위 정신을 직접 부여한다. 공산정부를 잃으면 제거되며 정권 복귀만으로 자동 복구되지 않는다.
- 2026-09-22 후속 보상 조정은 [첫 10개 명세](HOK_KOREAN_SECOND_WAVE_FIRST_10_SPEC.md)의 최종값으로 적용한다. 기존 수치에 가산하지 않으며 기존 326개, ID, 배치와 이미지는 유지한다. 협동 작업장의 공동구매 경로 산업 연구 75% 1회와 자율금융 II의 민공 건설 속도 +2% 등 기존 부가효과도 보존한다. 자율금융 II의 정치력은 별도 추가 강화값이 지정되지 않아 I의 일일 +1.2를 승계한다.
- 말단 중점에서 선택한 기간제 사업을 해금한다. 공동구매 조달·군수설비 집중 건설은 정치력 150을 쓰며 민공 점유와 사람·AI의 민공 수량 요건을 없앤다. 자율금융·현행생산 사업은 정치력 75와 민간공장 2개를 유지한다. 네 사업 모두 90일 동안만 효과를 받으며, 최대 동시 하나와 종료·취소 후 공통 90일 대기시간, 기존 취소 조건을 유지한다. 무료 공장·정치력·경험치를 반복 지급하지 않는다.
- 민공을 점유하는 자율금융·현행생산 사업에서는 2개 공장을 다른 건설에 사용할 수 없다. 이 두 사업의 사람 가용 민공 요건은 2개, AI 요건은 각각 24개·6개다. 모든 사업의 기존 AI 정치력 150 이상 조건과 기본 가중치 0.5는 유지한다.

## 배치와 이미지

새 10개는 실제 기존 부모 옆에 상대좌표로 붙였다. 공산주의 구역 오른쪽의 공간을 확보하기 위해 공화국 진입·민주·구국군·황실의 절대 기준점 4개를 오른쪽 10칸 이동했다. 해당 상대 자손은 함께 이동한다. 전체 범위는 x0~204·y0~24이며 높이·지속적 중점 패널·바로가기 설정은 유지한다. 이 이동은 기존 기능 변경과 별도로 기록한다.

기준선 실행에서 발견한 개마고원·소양강댐의 선행 선언 오류 2건은, 먼저 선언된 `KOR_devalue_the_won`을 기준으로 상대값을 재계산해 수정했다. 계산된 위치 (2,5)·(8,5)는 보존한다. 존재하는 ID라도 뒤에 선언되어 있으면 엔진이 상대 기준으로 등록하지 못한 실제 로그가 근거다.

[현재 354개 좌표 데이터](data/HOK_KOREAN_SECOND_WAVE_COORDINATES.json)는 이전 326개 명세와 구분한다. 사용자가 승인한 병렬 개편은 첫 경제정책 10개를 그대로 두고, 전국 협동조합 연합 `(75,13)`에서 Y1 x73·y14~17과 Y3 x77·y14~18로, 중공업 종합배정 `(98,13)`에서 P1 x96·y14~18과 P3 x100·y14~17로 나눈다. 네 시작 중점의 상대좌표는 왼쪽 `(-2,1)`·오른쪽 `(2,1)`이며 각 묶음 내부는 직전 부모 기준 `(0,1)`을 유지한다. 경제정책 뒤의 직렬 9개가 최대 5행의 병렬 묶음이 되어 공산 추가분의 범위는 y10~22에서 y10~18로 줄고, 전체 범위 x0~204·y0~24는 유지한다. 기존 326개와 첫 10개의 위치·조건·보상, 모든 중점의 ID·보상·35일 기간·AI·기존 상호배타 선택은 보존한다. 정적 좌표·직사각형 검사는 실제 연결선, 이름판, SHOW/HIDE, 이념 선택 후 화면 검증을 대신하지 않는다.

중점 진행 순서의 변경은 두 시작 선행조건에 한정한다. `HOK_KOR_yeo_rural_service_survey`는 `HOK_KOR_yeo_social_compact` 대신 `HOK_KOR_yeo_cooperative_federation`을, `HOK_KOR_pak_planning_secretariat`는 `HOK_KOR_pak_integrated_output_plan` 대신 `HOK_KOR_pak_heavy_industry_dispatch`를 요구한다. 후속 개발을 우선하면 Y3 보상은 종전보다 최대 140일, P3는 최대 175일 빨리 도달할 수 있다. 두 묶음을 모두 진행할 때 지도자별 완료 가능한 13개·기본 455일은 바뀌지 않는다. 이는 중단·다른 조건 대기를 제외한 계산이다.

새 중점 10개·정신 8개는 기존 공개 팩의 허용된 소재와 합성 방식을 재사용했다. 공산 경로색 RGB(116,45,48)을 배경에만 적용하고 소재·금속 테두리를 보존했다. 정책 단계 정신의 기존 I·II 표기는 보상 조정 후에도 유지한다. [출처·가공 기록](HOK_KOREAN_SECOND_WAVE_ICON_CREDITS.md)과 [매니페스트](data/HOK_KOREAN_SECOND_WAVE_ICON_MANIFEST.json)에 원본·가공·해시를 기록했다.

기존 신규 60개에 사용한 광택 오버레이도 프로젝트의 `gfx/interface/goals/HOK_KOR/shine_overlay.dds`로 복사하고 상대경로로 연결했다. 바닐라 오버레이는 공개 팩의 사용 허가와 구별해 기록한다. 기존 89개 아이콘 본체는 재생성하지 않았다.

## AI와 검증 경계

새 중점의 기본 AI 가중치는 2다. 전시에는 공동구매·현행 생산, 평시에는 지역금융·군수설비 선택에 각각 2배 가중한다. 선택을 강제하거나 기존 민주 역사 계획에 공산 중점을 삽입하지 않는다. 실제 진행 경쟁과 주요 보상 도달 시점은 장기 AI 검증 대상이다.

[326개 기준선 검증](HOK_KOREAN_FOCUS_VALIDATION_20260922.md)과 [이번 구현 기록](incidents/2026-09-22-korean-second-wave-first-policies.md)을 함께 읽는다. 정상 35일 진행, UI 비용 지불, 90일 완료·재착수, 협정 수락·거절·만료, 기존 저장, 다른 DLC, 멀티플레이는 각각 실제 관측 여부를 표시한다.

보상·비용 조정 전의 짧은 실행에서는 네 정책 선택의 중점 보상·정신 승계·기간제 사업 효과·정권 변경에 따른 취소를 재검증해 149 PASS/0 FAIL을 확인했다. 당시 임시 진단을 제거한 새 실행에서도 상대 기준 선언 오류 두 건과 진단용 dynamic token 경고가 사라졌다. 기존의 다른 오류는 남아 있다. 변경 후 최종값도 새 기대값으로 네 경로를 별도 실행해 149 PASS/0 FAIL을 확인했다. 두 사업의 민공 사용량 0과 다른 두 사업의 기존 사용량 2를 포함한 현재 결과는 [보상 변경 검증 기록](incidents/2026-09-22-korean-policy-rewards.md)에 구분했다. 강제 완료·활성화 검사는 정상 진행·비용 지불·연구 보너스 소모·90일 종료·화면·장기 AI 검증을 대신하지 않는다.

보병장비 한정 생산량 +10%는 이번 두 정책 묶음과 분리한 미결 항목이다. 약 -9.09% 생산비 대안은 아직 선택되지 않아 기존 조달 국민정신에 적용하지 않았다.

후속 내정 9개는 최초 추가 때 기존 336개 정의를 원문 그대로 보존했다. 당시 별도의 네 개 새 게임 진단은 **199 PASS / 0 FAIL**이며 기존 경제정책 선택 보존·새 정신 강화·사업 활성화와 정권 변경 취소를 확인했다. 이는 병렬 개편 전의 기록이다. 첫 10개의 149 PASS나 정상 35일·90일·화면 검증과 합쳐 표현하지 않는다. [후속 작업 기록](incidents/2026-09-22-korean-communist-governance.md)에 결과와 한계를 기록한다.

기술보급·계획행정 9개를 최초 추가할 때 기존 345개 중점 정의·좌표와 기존 내정 4개 사업의 정의를 보존했다. 이 보존 기록은 병렬 개편 전의 상태다. 새 사업 4개는 기존 후속 내정 범주의 활성·대기 플래그를 공유한다. 후속 내정 전체 8개 중 최대 하나와 기존 경제정책 4개 중 최대 하나를 병행하는 구조이며 새 범주나 세 번째 동시 실행 슬롯을 만들지 않는다. 병렬 가지 어느 쪽을 먼저 진행해도 사업이 보이도록, 원래 한국인 국가에서 지방협의회 정례화·생산능력 정기점검·공동업무 회계 공개·현장 기술대표단 중 하나를 완료하면 공유 범주를 표시한다. 개별 사업의 해금·지도자·정부 조건은 유지한다. 이번 결과는 [기술보급·계획행정 작업 기록](incidents/2026-09-22-korean-communist-development.md)을 따르며 앞선 149·199 검사에 합산하지 않는다. **현재 병렬 배치의 새 선행 경로·사업 범주 공개·연결선·명판·SHOW/HIDE는 아직 런타임 검증 전이다.**

병렬화 후 소스·좌표·선행·보상 보존과 가지별 도달성의 정적 검사 결과는 [병렬 배치 기록](incidents/2026-09-22-korean-communist-parallel.md)을 따른다. 게임 실행 결과와는 구분한다.
