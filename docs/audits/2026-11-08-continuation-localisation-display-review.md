# 계속개발 내용의 내부 표식·변수 현지화 표시 검토

작성: **2026-11-08 (Asia/Seoul)**. **아래 본문은 최초 문서화 전용 검토 당시의 기준과 결과다.** 이후 사용자가 표시 수리 구현·실행 검증을 승인했으며, 현재 적용 내용과 실제 관측·남은 검증은 [후속 구현 기록](../incidents/2026-11-08-localisation-display-implementation.md)을 따른다. 최초 검토 당시의 미적용·실행 없음 문구를 현재 상태로 해석하지 않는다.

중복을 제거한 표시 점검 대상은 **8개 고유 키**다. **국토개발 2개는 사용자 화면에서 원문 노출이 확인**됐고, **나머지 6개는 현지화 정의 없이 일반 조건·효과 또는 임무 취소 조건에 놓인 소스상 후보**다. 8개 모두를 재현된 UI 오류로 기록하지 않는다.

최초 요청은 문서화 전용이었다. 이 검토 당시에는 게임 코드·현지화 파일·지도·사용자 설정을 수정하거나 게임·검사 스크립트를 실행하지 않았다. 후속 구현과 검증은 위 별도 기록에서 구분한다.

후속 작업은 다음 자료를 해당 조건에 맞춰 먼저 읽는다.

- **국토개발 표식의 의미와 기존 저장 분기를 다룰 때:** [현재 CNDP 명세](../HOK_KOREAN_CNDP_STATE_DEVELOPMENT_PLAN.md)와 [구현 기록](../incidents/2026-11-08-korean-cndp-state-development.md)을 읽는다. 조건을 숨기는 작업이 새/구형 체계를 통합하거나 완료 이력을 바꾸는 작업이 되어서는 안 된다.
- **시민사회 변수·증거 보전 표식의 수명과 실제 효과를 확인할 때:** [재벌·시민사회 명세](../HOK_KOREAN_CHAEBOL_CIVIL_SOCIETY_SPEC.md)를 읽는다. 표시명을 바꾸는 수리와 변수 값·범위·초기화·365일 표식 수명 변경을 구분한다.
- **지역명·설명이 현재 지도와 다른 사례를 함께 수정할 때:** [현행 지도 기준 코드 정렬 계획](../HOK_STATE_REFERENCE_ALIGNMENT_PLAN.md)의 D-01~03과 구분한다. 이번 8개는 정확한 표시 키 부재 후보이며, 키가 존재하지만 설명이 낡은 사례와 별도 집계다.

계속개발의 중점·결정·이벤트, 아이디어·modifier·연구망·MIO·습격·세력·인물, GUI·scripted localisation과 양 언어 파일을 대상으로 했다. HOK 접두어와 기여 주석뿐 아니라 실제 표시 문맥·원본 정의·기존 조건도 대조했다. 모든 내부 식별자의 현지화 필요성이나 모든 UI 상태를 전수 실행한 검토는 아니다.

## 2. 집계 기준과 읽기 대조 결과

1. **고유 키 수**와 사용 횟수·결정 수·선택지 수를 구분한다. 국토개발 13종이 같은 2개 키를 공유하므로 26개 결함으로 계산하지 않는다.
2. 정확한 이름의 정의가 저장소 양 언어·활성 번역·설치 원본에 없는지 확인한다. 비슷한 접두어의 UI 문구가 있어도 정확한 변수 이름의 정의로 세지 않는다.
3. 일반 `available`, 숨기지 않은 효과, 취소 조건 등 화면에 연결될 수 있는 경로를 기록한다. 사용자 지정 툴팁으로 가려진 조건, 내부 표시 필터·AI·on_action·이벤트 자격 검사, 단순 표식 설정만으로 UI 결함을 확정하지 않는다.
4. 후보의 기본 변수 효과·취소 조건 렌더링은 실제 관측 전 `UNPROVEN`이다. 정의 부재는 소스로 `CONFIRMED`여도 화면 노출까지 같은 등급은 아니다.

읽기 검색에서 확인한 결과:

- 저장소 현지화 **94개 파일·47쌍**, 한국어와 영어 각각 **3,092개 고유 키**. 대소문자를 구분한 양 채널 키 집합 차이는 0이다. 양쪽 모두에 없는 키는 이 일치만으로 발견되지 않는다.
- HOK 접두어 신규 후속 중점 **249개**(한국 209·일본 40)의 이름·설명은 정의가 있다. GUI의 inlay ID는 중점 개수에서 제외했다.
- 확인한 중점의 HOK/KOR 명시적 사용자 툴팁 29개, 바로가기 이름 8개와 새 결정·이벤트의 명시적 이름/제목/본문/선택지/툴팁에서도 추가 확정 누락은 찾지 못했다.
- 조사한 직접 효과 툴팁, 시민사회 GUI·scripted localisation 반환 키, MIO 특화 15종, 습격·세력·과학자 이름에서도 별도 추가 누락은 확인하지 못했다.

이 수치들은 이번 소스 검색·대조의 범위다. 새 loader 등록·모든 UI 렌더링·기존 저장·영문 번역 전체 품질의 통과 수가 아니다.

## 5. 집계에서 제외한 항목

- 공산·파시스트·만주 사업의 진행/대기 표식은 현지화된 `custom_trigger_tooltip`으로 감쌌다. 원시 표식에 별도 이름이 없다는 이유만으로 중복 결함으로 세지 않는다.
- `HOK_KOR_policy_cooperation`, `HOK_KOR_policy_civic_reform`, `HOK_KOR_policy_public_ownership` 등 시민 정책·활동 표식은 [시민 UI 현지화](../../localisation/korean/HOK_KOR_civic_ui_l_korean.yml) 46–63행에 이름이 있다.
- 위기 내부 자격 표식 `HOK_KOR_civic_reform_pressure`, `HOK_KOR_prosecutor_crisis_pending/active/cooldown`은 확인한 이벤트·on_action 경로만으로 표시 누락에 포함하지 않았다.
- 북사할린 완료·항공/추진제 해금·관세/면허 제안 대기 등 표시 여부·대상 선택 필터용 표식, 단순 완료 표식 설정은 일반 요구조건 노출 수에 넣지 않았다. 필터 렌더링이 나중에 관측되면 별도 후보로 추가한다.
- `KOR_Bugil_Hwang` 등 과학자 4명의 인물 ID와 소문자 이름 키는 서로 다른 역할이다. 실제 이름 키는 두 언어·활성 번역에 모두 있으므로 대소문자만 보고 누락으로 세지 않는다.
- 기존 `STATE_KR_992`, `KOR_jet_engines`, `kor_hok_gookppong_middle_power_enabled_flag`, `JAP_zaibatsus_factories` 등은 이번 계속개발 신규 누락 8개와 분리한다. 오래된 미정의 키나 필터 후보의 정상 여부를 이 제외로 보증하지 않는다.
- 선택적인 `_desc` 부재, 런타임 문자열 매개변수, 기존 빈 사건 본문, 동적 건물 툴팁 형식도 즉시 원문 노출 결함으로 합산하지 않았다.
- 현재 지도와 다른 옛 지역명·조건 설명은 별도의 코드 정렬 계획 D-01~03에서 관리한다.

## 6. 후속 표시 수리 방향 — 미적용

1. **내부 식별자와 저장 의미를 보존한다.** 표식·변수 이름을 한국어로 바꾸거나 조건·OR/NOT 구조를 삭제하지 않는다. 비용·보상·변수 값/범위·표식 수명·완료 이력·구형 저장 분기를 그대로 둔다.
2. **L-01 체계 분기 표식은 내부 조건으로 처리하는 방향을 우선 검토한다.** 유저가 판단할 필요 없는 버전 표식을 표시하려고 기계적인 번역만 붙이지 않는다. 조건을 숨기는 wrapper의 현행 문맥·엔진 적법성을 확인하고 실제 조건은 유지한다.
3. **L-02 완료 조건은 주 단위의 이해 가능한 문구로 표시한다.** 예: “해당 주의 개발 사업을 아직 완료하지 않음”. 선행 조건과 즉시 취소 조건의 긍정/부정 의미를 각각 맞춘다. 완료 표식 자체를 숨겨 재사용 제한을 제거하는 변경은 하지 않는다.
4. **L-03~06은 실제 기본 툴팁부터 확인한다.** 변수명 현지화 또는 정확한 사용자 지정 조건/효과 툴팁 중 현재 엔진에서 동작하는 최소 방식을 선택한다. GUI의 기존 숫자 표시는 유지하며, 효과를 숨긴다면 플레이어에게 필요한 수치·조건 설명을 함께 보존한다.
5. **L-07은 정변 취소 조건의 의미를 보존한다.** 기관 장악 감소·증거 확보·정책 변경의 대안 구조를 유지하고 증거 확보 여부를 알아볼 수 있게 표시한다. 표식의 365일 수명을 바꾸지 않는다.
6. **L-08은 내부 집계 노출을 억제하는 방향을 검토한다.** 현재 반복 사업의 횟수 제한으로 사용하지 않는 누적 기록이다. 이미 있는 산업지원 안내를 유지하며 새 상한이나 할당량을 만들어 설명하지 않는다.
7. 한국어·영어 paired 파일과 실제 활성 영문 번역의 동명 파일 덮어쓰기를 확인한다. 한국어 본문을 양 채널에 보존하는 현재 프로젝트 계약과 UTF-8 BOM을 지킨다. 기존 전체 현지화 파일을 덮지 않는다.

이 방향은 설계 후보이며 코드 패치가 아니다. 원문을 숨기기 위해 실제 조건을 완화하거나 `always=yes`로 바꾸지 않는다.

## 7. 미실행 검증과 이번 문서화 결과

후속 구현·진단이 별도로 승인되면 다음을 분리해 확인한다.

- 키·참조·BOM·locale·동명 파일 덮어쓰기의 소스 확인.
- 전체 프로세스 재시작 뒤 한국어·활성 영어 번역의 실제 툴팁. L-01~02는 국토개발의 사용 불가/가능·완료·취소 표시를 나누어 관측한다.
- L-03~06은 영향력 경계의 요구조건, 조달/개혁의 직접 효과, 사건 선택지를 확인한다. L-07은 정변 임무 취소 조건, L-08은 중점 초기화와 산업지원 효과를 각각 본다.
- 표시 변경 전후 조건의 참/거짓·비용·보상·일회/반복·취소 동작·저장 값이 같은지 별도로 확인한다. 문구 개선과 게임 로직 보존을 함께 판정한다.
