## 4. 기존 콘텐츠 보존 계약

1. 기존 266개 중점의 ID·이름·설명·아이콘·보상·선행조건·상호배타·분기 표시 규칙과 기존 `ai_will_do`의 값·조건을 보존한다. 계획된 예외는 현재 `cost = 10`인 152개를 `cost = 5`로 바꾸는 기간 변경이다. 기간과 선택지 변화 이후의 실제 AI 행동이 같다고 가정하지 않는다.
2. 새 중점은 기존 경로를 막지 않는 선택형 옆가지 또는 후속 가지로 붙인다. 기존 중점 사이에 새 의무 선행조건을 삽입하거나 새 숨김 조건으로 기존 경로를 가리지 않는다.
3. 위치 조정이 필요하면 별도 배치 변경으로 명시한다. 위치 변경을 이유로 기존 연결·접근 조건을 바꾸지 않는다. 기존의 이념별 배타 관계는 유지한다.
4. 이미 35일인 ‘아시아 민주주의의 선봉’과 ‘온건외교 중단’, 앞서 추가한 의용군 파병 허용 및 긴장도 완화 효과를 기준선으로 보존한다.
5. 기존 ‘대한의용군단’의 필요 사단 감소·파병 규모 증가 효과를 유지한다. 앞선 의용군 해금을 다시 잠그는 조건을 추가하지 않는다.
6. 기존 국가·인물·이벤트·국민정신·결정·현지화 키와 원작 크레딧을 보존한다. 신규 이식 콘텐츠는 프로젝트의 기존 접두사 관례와 전체 ID 충돌 검색을 거쳐 독립된 ID로 만든다.
7. 신규 산업 콘텐츠를 이유로 한국 지형·주·프로빈스 번호를 재설계하지 않는다. 기존 지역 대상 보상은 해당 주의 소유·통제와 실제 HoK 배치를 확인한다. 지도 변경이 필요한 후보는 별도 작업으로 분리한다.
8. 바닐라 원본과 Workshop 폴더는 읽기 전용이다. 기존 일본·중국 트리나 전역 데이터베이스를 한국 확장을 위해 덮어쓰지 않는다.

기간 단축 시에는 중점 정의의 비용만 문맥별로 편집한다. 다른 디렉터리의 비용이나 `days = 70`, 결정 기간 등을 일괄 치환하지 않는다. 프로덕션 수정 때는 [AGENTS.md](../AGENTS.md)의 인접 기여 주석 형식과 인코딩 보존 규칙을 따른다. 기존 주석도 보존한다.

## 5. 플레이 경험과 진행 속도

### 5.1 확장의 중심

이미 있는 기관·동맹을 활용하는 후속 선택을 늘린다. 기존 ADD·KAI·포항제철·대함대·아시아 연합·입헌군주정 창설을 이름만 바꿔 다시 만들지 않는다.

신규 보상은 기술 전문화, 정책 선택, 비용을 지불하는 사업, 동맹 협력, 군 조직 운영에 우선 배분한다. 기존 보상을 임의로 줄이지 않으며, 신규 공장·연구 슬롯·영구 능력치의 총량은 별도로 설계한다. 미적용 후속 모듈의 실제 수치는 아직 확정하지 않는다.

후속 개발은 [중점 보상 설계 기준](HOK_KOREAN_FOCUS_REWARD_GUIDELINES.md)에 따라 완료 가치가 체감되는 강한 보상을 기본으로 설계한다. 최근 강화 사례를 참고하고 기존 혜택과 상위 단계 승계를 보존한다. 작은 보상만 반복해 중점 수를 채우지 않는다.

### 5.2 35일화가 바꾸는 것

중점 기간만 절반으로 줄여도 기존 공장·연구 슬롯·전쟁 목표·군대 보상을 더 빨리 받게 된다. 이는 의도적인 진행 속도와 세력 균형의 변화다. 완료 효과가 같다는 이유로 ‘밸런스 변화 없음’이라고 보고하지 않는다.

특히 ‘건설 붐’의 대공황 제거, ‘한강의 기적’의 연구·산업 보상, ‘기갑 선봉대’의 부대 지급, ‘만주 선제타격’의 전쟁 목표 도달 시점을 비교할 필요가 있다. 이 문서에서는 해당 보상을 재조정하지 않는다.

새 중점의 총수는 여러 정치 경로·선택형 가지를 합친 규모다. 1936~1945의 약 10년을 35일 단위로만 계산해도 약 104개 분량이므로, 450개 전체를 한 플레이에서 완료하도록 설계하지 않는다. 이 계산은 저장 진행도·중단·이벤트 등을 제외한 설명용 근사치다.

### 5.3 중점 비용과 별개인 대기

`KOR_strengthen_government_support`는 365일 국민정신을 부여한다(한국 중점 4467~4471행). `KOR_national_unity`는 그 국민정신이 없어야 진행한다(4500행). ‘북벌론’은 분열된 정부의 제거를 요구한다. 따라서 70일 중점을 35일로 바꿔도 이 대기는 남는다.

이 기간에 의회·행정·기술교육·군수·해외지원 옆가지를 선택하도록 설계한다. 365일 효과를 삭제하거나 줄이는 것은 이번 확장 초안에 포함하지 않는다. 1941/1946 선거와 기존 결정의 시행 기간도 중점 비용과 별개로 보존한다.

## 8. 코드 재사용과 한국화 원칙

이식 단위는 중점 한 블록이 아니라 **중점 → scripted effect/trigger → 변수·국민정신 → 결정·이벤트 → 현지화·아이콘**의 실제 연결 묶음이다. 모든 후보가 이 요소를 전부 필요로 하는 것은 아니며, 호출되는 범위만 추적한다.

일본 산업 중점은 `JAP_add_or_modify_early_industrialization`과 산업 변수·동적 국민정신을 함께 사용한다. 독일 산업의 일부 scripted effect는 툴팁을 선택하고 실제 효과는 별도 변수가 담당한다. 중점 이름과 태그만 바꾸고 연결을 누락하면 표시와 실제 보상이 달라질 수 있다.

원본의 정책 선택 구조와 효과 실행 순서를 최대한 재사용하되 다음을 한국에 대응시킨다.

- 기존 한국 인물·MIO·아이디어·주·프로빈스와 실제 대상 범위.
- `ROOT`, `FROM`, `PREV`, 이벤트 대상, 변수 소유 범위와 초기화·저장·회수 시점.
- 국가 고정 참조, 외교 상대 부재·내전·괴뢰화·패전 등의 조건.
- DLC가 없는 경우의 동작. 원본 트리 최상위에서 보장하던 DLC 조건도 확인한다.
- 새 중점 ID와 연쇄 이벤트·결정·현지화 키. 원본 국가와 충돌하거나 원본 이벤트를 오발시키지 않는다.

일본 황실 영향력·육해군 파벌과 미국 의회 전체 시스템은 첫 묶음에서 제외하는 것을 제안한다. 기존 한국 설정과 연결되는 규모가 크므로 필요성이 확인되면 독립된 설계로 다룬다.

원본 출처, 정확한 버전·해시, 가져온 기능, 한국화한 부분을 모듈별로 기록한다. 바닐라와 원작 HoK에서 상속한 코드·자산을 신규 창작물로 표기하지 않는다. 원본 라이선스·크레딧을 제거하거나 임의로 새 라이선스를 붙이지 않는다.

### 현지화 예시

제안 이름: **국가전력조정위원회**

> 팔도의 공장과 광산이 안정적으로 가동되려면 발전과 배전이 하나의 계획 아래 움직여야 한다. 전력 수급을 조정하고 산업지대에 필요한 전력을 공급할 것이다.

이 문장은 제안용 신규 문구이며 실제 localisation 파일에 추가하지 않았다. 한국이 이미 독립국인 HoK의 설정, 기존 인물·기관·정치 노선에 맞춰 설명을 쓴다. 일본 식민통치나 중국의 초기 상황을 지명만 바꿔 남기지 않는다. 기존 중점의 문구를 일괄 개작하지 않는다.

구현 시 현행 English/Korean 대응 파일 계약과 UTF-8 BOM, 안정된 기존 키, 색상·아이콘·치환 토큰을 보존한다. `Korean Language` 의존 계약 변경은 이 확장 문서에 포함하지 않는다.

## 9. 수량과 단계별 작업안

아래 표는 최초 설계의 우선순위와 규모를 보존한다. 당시 266개에서 최종 450~470개로 확장하려면 신규 184~204개가 필요하며, 첫 60개는 그중 일부다. 후속 요청으로 기간 변경과 첫 60개는 구현했지만 최종 수량·일정이나 나머지 개별 중점 명세가 확정된 것은 아니다.

첫 콘텐츠 묶음에서도 수리·연안전, 항공 설계 선택, 군수 규격화처럼 비교적 분리 가능한 후보를 먼저 구현한다. 지역 개발 결정과 핀란드식 지역작전은 기존 결정 및 상태 회수 구조를 검토한 뒤 배치한다.

기존 파일을 쪼개거나 별도 분기를 로드하는 방식은 구현 전 loader 계약을 확인한 뒤 정한다. 같은 ID의 부분 정의나 두 번째 한국 일반 트리를 추가하면 자동 합쳐진다고 가정하지 않는다. 새 가지를 파일로 분리하더라도 기존 한국 트리와 연결하는 방법을 명시한다.

## 11. 최초 설계의 검증 계획

다음은 최초 설계 때 정한 검증 기준이며 항목 전체가 완료되었다는 뜻은 아니다. 공통 기준은 [검증 점검표](VALIDATION_CHECKLIST.md)를 따른다. 1차 확장의 실제 기능 관측과 남은 검증은 [1차 구현 기록](incidents/2026-09-21-korean-focus-expansion.md)에 유지하며, 이후 좌표 재배치의 UI 검증은 [재배치 설계](HOK_KOREAN_FOCUS_LAYOUT_PLAN.md)에서 별도로 추적한다.

- 정적 보존: 기존 266개 ID·현지화 키 유지, 기간 변경 대상 152개와 나머지 비용 구분, 보상·선행·배타·AI의 의도치 않은 변경 없음.
- 참조·범위: 신규 ID 충돌, 호출 의존성, 국가/주 범위, 이벤트 송수신, 변수 초기화·회수, DLC 없는 경로 확인.
- 화면: 지원 bookmark와 이념 경로에서 트리 열기, `HIDE`/`SHOW`, 바로가기, 해상도·배율, 연결선·설명 표시 확인.
- 행동: 모듈별 정상 완료와 중요한 차단 경로를 확인. 외교 제안의 수락/거절, 상대국 부재, 개발 대상 상실, 사업 중복 실행을 해당 기능에 맞게 선정.
- 진행 속도: 35일화 전후의 주요 내정 회복·연구·군비·만주전쟁 도달 시점을 비교. 365일 대기와 기존 선거가 유지되는지 확인.
- 기존 변경 회귀: 온건외교 중단의 파병 허용·긴장도 완화와 대한의용군단의 사단 수·규모 효과 유지 확인.
- 세이브: 새 게임 저장/재로드와 변경 전 세이브 호환을 구분. 기존 완료 중점의 보상은 자동 재지급된다고 가정하지 않음. 이전 세이브용 마이그레이션은 필요성이 입증되면 별도 설계.
- AI·멀티플레이: 기간 단축 후 AI 경로와 전쟁 시점 확인. 멀티플레이 호환성을 주장하려면 동일 구성의 동기화 검증이 추가로 필요.
- 실행 증거: 허용된 실행 전에 기존 로그를 보존하고, 전체 재시작·실제 플레이 구성·전후 로그·관찰 결과를 기록. 파서 통과나 메인 메뉴 진입만으로 완료 판정하지 않음.

보존 계약에 충돌하는 후보는 제외하거나 기존 콘텐츠를 유지하는 방식으로 재설계한다. 문서에 적는 것만으로 기존 중점 삭제·보상 축소·필수 선행관계 변경이 허용되는 것은 아니다. 새 DLC 요구나 지도 ID 변경이 필요한 후보도 자동 적용하지 않고 별도 범위로 분리한다. 최초 문서화 단계에서는 어느 것도 선택하지 않았으며, 후속 구현·검증 결과는 아래와 구현 기록에서 구분한다.

## 12. 최초 문서화 기록과 후속 검증 상태

최초 문서화에서는 한국 중점·비용 집계, 소스의 365일 대기, 앞선 의용군 변경, 대표 바닐라 중점과 일부 의존성을 확인했다. 이름·모듈 조합·수량·배치·보상은 설계 제안으로 제시했으며 프로덕션 수정·게임 실행·커밋·업로드는 하지 않았다. 이 기록은 후속 구현 요청과 구분하여 보존한다.

후속 1차 구현에서는 기존 266개를 보존하고 152개만 35일로 단축했으며, 신규 60개를 추가했다. 정적 검사와 설치본 1.19.3의 제한된 엔진 검증을 수행했다. 아래는 모두 좌표 재배치 전 기능 검증 이력이다. 2026-09-21 native-smoke의 **PASS 104 / FAIL 0 / SKIP 0**은 다음 관측을 합산한 결과다.

- 임시 정부·세력 설정 1건, 선택한 중점 58개 완료, 미선택 중점 2개 미완료, 최종 국민정신 16개 존재, 교체 전·미선택 국민정신 10개 부재.
- 지역 결정 4개 활성, 평안(527)의 실제 소유권 상실 후 취소·완료 플래그 부재·소유/통제 복원 각 1건, 다른 사업 3개 활성 유지.
- 실제 BHU 관세·면허 협정 수락 국민정신을 별도 2건 관측했고, 쌍방 면허 관계 보정 2건을 확인했다. 이어 BHU 세력 이탈 1건, 두 협정 국민정신 제거 2건, 양방향 관계 보정 제거 2건을 확인했다.

중점은 `complete_national_focus`, 결정은 스크립트로 활성화했다. 정상 35일 진행·UI 선행/배타 잠금·실제 비용 차감·180일 완공을 검증한 결과로 확대하지 않는다. 미선택 2개 보상, 외교의 다른 실패/만료 경로, DLC 없는 환경·AI·저장·멀티플레이 등 남은 범위는 [구현 기록의 검증과 한계](incidents/2026-09-21-korean-focus-expansion.md)에 통합했다. 1.19.2 호환성과 전체 확장 완료는 미확인이다.

로그 4개·해시·관측 요약은 로컬 `RUNTIME/POST-SMOKE/`에 보존했으며, 이 실행의 기준선 대비 신규 정규화 오류 서명은 0개다. 체크섬 `8581`은 임시 진단 포함 실행의 값이다. 임시 파일 2개는 해시 대조 후 삭제하여 `RUNTIME/temporary-files-removed.json`에 기록했다. 재배치 전 확장 작업의 진단 없는 최종 재시작(체크섬 `86c5`), 한국 1936 새 게임과 당시 대표 가지 UI, 1월 2일 18시까지 진행을 확인했다. 당시 일부 연속 바로가기는 시작 중점이 화면 하단에 걸려 스크롤이 필요한 한계가 남았다. 상세 범위는 구현 기록을 따르며, 이 실행을 새 좌표의 최종 검증으로 인용하지 않는다.

첫 넓은 좌표 재배치는 정적 보존 확인과 대표 화면 검수를 진행했다. HIDE에서는 초기·공화국·공산·민주·구국군·황실 상태를, SHOW에서는 초기·민주 선택 상태와 다른 황실 가지가 남는 표시를 관측했다. 첫 HIDE 실행은 최종 유전·황실 수정 전 소스였으며, 이 관측을 12상태 전체의 최종 런타임 통과로 확대하지 않는다. 만주 선 간섭 해소는 후속 화면에서 확인했고 바로가기 배율 생략 시험은 잘림을 해결하지 못했다.

현재 압축 적용 소스는 `23049d0d607ecbdfe5454da644c292a55e7d903a4dca1b4f3d930105cde66242`다. 기간·효과·선행·배타·조건·AI는 그대로이며, AA58을 기준으로 한 326개 비배치 focus 토큰 대조에서 차이가 없었다. 새 좌표는 HOI4 1.19.3·27bf, 새 1936 한국 게임 일시정지, HIDE 초기 상태, 1600×900·GUI 배율 1에서 전체 분야의 위아래·좌우를 확인했다. 28개 화면에서 아이콘·이름판 겹침 및 관계없는 선의 중점 가림은 0건 관측했고, 지속적 중점 패널 공간도 확인했다. HIDE/SHOW 12개 조건은 정적 위치 불변 검사이며 이념 전환·SHOW 런타임은 이번에 재실행하지 않았다. 공유 부모 연결선·정상 3자 상호배타 연결을 유지하며 모든 선끼리의 교차가 0이라고 주장하지 않는다. 결과와 만주 바로가기 한계는 [현재 압축 작업 기록](incidents/2026-09-21-korean-focus-compact.md)을 따른다.
