# 한국 역사 AI 중점 계획 갱신 기록

작성: 2026-09-21. 상태: **소스 적용·정적 검사 완료 / 게임 실행 미실시**.

이번 변경은 김구 민주 경로의 역사 AI 중점 선택 계획을 현재 한국 중점 트리에 맞추는 사용자 승인 구현이다. 앞선 중점 추가·35일화·압축 배치·보상 강화와 구분한다. 소스의 순서와 조건은 확인했으나 실제 AI 선택과 조건부 계획 전환은 아직 게임에서 검증하지 않았다.

## 2. 확인한 문제와 적용 정책

기존 계획은 51개 중점만 나열하여 확장 중점을 포함하지 않았고, 군 예산 증액이 선행 중점인 다음 전쟁 준비보다 앞에 있었다. 정부지원 강화와 국가 단결 사이의 35일 중점 10개는 명목상 350일로, 기존 365일 국민정신 종료 조건보다 짧았다. 이는 소스의 순서·기간 비교로 확인한 사실이며 당시 AI가 실제로 멈췄다는 재현 결과는 아니다.

기본 목록은 **106개 = 기존 목록 51개 전부 + 연결에 필요한 기존 중점 7개 + 확장 중점 48개**로 갱신했다. 기존 51개를 삭제하지 않고 선행 순서에 맞게 재배열했다. 한국 트리 326개 자체를 다시 쓰거나 배치한 것이 아니라 역사 AI의 선택 목록을 수정한 것이다.

| 추가 역할 | 기존 중점 ID |
|---|---|
| 공군·국산 설계 연결 | `KOR_daehanminguk_gonggun`, `KOR_new_fighter`, `KOR_korea_aerospace_industry` |
| 육군 확장 연결 | `KOR_research_army_doctrine` |

| 후반 해군 연결 | `KOR_invitation_of_foreign_naval_designers`, `KOR_commerce_raiding` |

생산은 표준규격 대량생산, 항공은 국산 설계 역량 집중을 선택한다. 반대편 `HOK_KOR_flexible_production_lines`와 `HOK_KOR_foreign_aircraft_designs`는 기본 계획의 `focus_factors`에 각각 0으로 기재했다. 해당 계획의 선택 정책이며 플레이어 선택 조건이나 중점 자체의 AI 가중치를 바꾸지 않는다.

확장 60개 중 기본 목록 48개와 창설 후 지원 5개를 합쳐 **53개**를 반영했다. 기본 목록과 세 지원 계획의 양수 우선순위 대상을 합친 전체 고유 중점은 **118개**다. 다음 확장 7개는 이번 계획에서 제외했으며 콘텐츠를 삭제하거나 모든 AI에서 금지한 것은 아니다.

| 제외 사유 | ID |
|---|---|
| 선택한 생산 방식의 대안 | `HOK_KOR_flexible_production_lines` |

## 3. 보존한 기본 계획 설정

`allowed = { original_tag = KOR }`와 기존 `enable`을 보존했다. 활성 대상은 역사 중점 사용과 `KOR_AI_BEHAVIOR = DEFAULT`가 함께 성립하거나, `KOR_AI_BEHAVIOR = DEMOCRATIC`를 지정한 경우다. 규칙 ID의 대소문자를 기존대로 두었으며 다른 파일의 표기를 이번 작업으로 정규화하지 않았다.

| 보존 항목 | 값 |
|---|---|
| 연구 가중치 | `infantry_weapons = 50.0`, `infantry_tech = 15.0`, `artillery = 8.0`, `support_tech = 6.5` |
| 국민정신 선택 | 기존 빈 `ideas` 블록 |
| 동맹 전략 | 중국 `CHI = -500`, 중공 `PRC = -500`, 미국 `USA = 500` |

동맹 전략값은 가입 확률이나 강제 가입 효과가 아니다. 연구·생산 정책과 결정의 선택 태도를 그대로 두었으므로 중점으로 결정을 해금해도 즉시 사용하거나 상대국이 협정을 수락한다는 뜻은 아니다.

## 4. 조건부 지원 계획 3개

세 지원 계획은 모두 한국 원래 태그, 기존 역사/민주 게임 규칙, `KOR_president_kim_gu` 완료, 현재 민주 정부를 요구한다. 김구 조건은 중점 완료 검사이며 현재 지도자 인물 검사와 다르다. 각 계획의 `weight`는 1.0이다.

지원 계획에는 별도의 `ai_national_focuses` 목록 대신 `focus_factors`를 사용한다. 20·50은 가중치이며 20%·50% 확률이나 즉시 선택 명령이 아니다. 각 `abort`에는 `NOT = { AND = { 해당 enable 조건 전체 } }`로 활성 조건의 논리적 부정을 그대로 넣었다. 조건 상실 시 지원을 종료하도록 작성했으나 엔진의 평가 시점과 진행 중 중점 처리까지 입증한 것은 아니다.

### 방어전 지원

계획 ID는 `HOK_KOR_historical_defense_plan`이다. 공통 조건에 더해 방어전 중, `KOR_national_unity`와 `KOR_expend_military_budget` 완료, 대상 두 중점 중 하나 이상 미완료를 요구한다.

| 대상 | 가중치 |
|---|---:|
| `KOR_call_up_the_rokrf` | 50 |
| `KOR_homeland_defence_special_act` | 50 |

두 중점은 기본 목록에도 남긴다. 평시·부모 미완료 상태에서는 지원하지 않으며, 기존 방어전 조건을 삭제하거나 전쟁을 만들지 않는다. 방어전 종료, 공통 조건 상실, 두 중점 모두 완료 시 중단 조건이 참이 된다.

### 만주 승전 후 아시아연합 창설

계획 ID는 `HOK_KOR_historical_asian_union_formation_plan`이다. 공통 조건에 더해 독립국·세력 미가입, 기존 글로벌 플래그 `kor_triumph_for_the_manchuria_flag`, 아시아연합 창설 미완료, 유럽 해방 미완료를 요구한다. 유럽 해방 완료를 제외해 기존 상호배타 경로와의 충돌을 피한다.

승전 플래그를 지급하거나 전쟁·세력 탈퇴·창설을 강제하지 않는다. 각 중점의 선행·착수 조건은 그대로 적용되며, 다른 세력 가입국·종속국이면 이 지원 계획은 활성화되지 않는다.

| 검사 | 확인 결과와 한계 |
|---|---|

위 정적 검사 결과는 로컬 검사 기록과 소스를 근거로 한다. 게임 실행 결과는 포함하지 않는다. 30개 논리 시나리오는 역사/비역사·명시 민주/다른 규칙, 평시/방어전·부모 미완료·목표 완료, 승전 전후·종속·세력 가입·상호배타, 창설 전후·지도국 상실·협력 완료 및 민주정·김구 조건을 다룬다.

**실제 우선 선택, 진행 중 중점의 전환·유지·취소, 게임 규칙 ID 해석, 기존 저장·새 저장 왕복, 멀티플레이, 1939 북마크, DLC 미보유 경로와 장기 AI 행동은 미검증**이다. 선행 순서 검사와 Boolean 모델은 계획 선택 경쟁·평가 주기·자동 우회나 대체 선택을 증명하지 않는다. 이전 실행의 로그나 배치·리밸런스 화면을 이번 검증 증거로 재사용하지 않는다.

후속 게임 검증 항목은 다음과 같다.

1. 완전 재시작 후 버전·DLC·모드·로드 경로·새 체크섬을 기록하고 기존 로그와 새 관련 오류를 비교한다.
2. 역사 기본값과 명시 민주에서 김구 경로, 생산·항공 선택, 정부지원 대기, 국가 단결과 군 예산 증액의 실제 진행을 확인한다. 비역사 기본값과 다른 이념 규칙도 대조한다.
3. 방어전 시작·종료와 부모/목표 완료 전후의 지원·중단 및 실제 다음 중점 선택을 확인한다. 진행 중 중점 영향은 별도 관측한다.
4. 만주 승전·세력 가입·종속·유럽 해방·연합 창설·지도국 상실에 따른 지원 전환을 확인한다.
5. 중형전차 미연구, 세 주 소유·통제·부지 부족 상태의 선택을 관찰한다. 연구·생산·결정 정책의 추가 조정은 별도 범위로 검토한다.
6. 새 저장 왕복과 기존 저장 호환성을 구분하고, 1939·DLC 미보유·멀티플레이는 실제 실시한 범위만 기록한다.
