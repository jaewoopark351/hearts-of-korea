## 3. 반복과 보상의 의미

- 90일은 자원을 받기까지의 **공사 기간**이다. 사용 즉시 자원을 주거나 90일 동안만 효과를 주는 방식이 아니다.
- 민간공장 9개는 공사 중 사용하는 용량이다. 공장을 삭제하거나 영구 소모하지 않으며, 공사가 끝나면 점유를 해제한다. 착수에 필요한 가용 민공 조건은 **9개 이상**이다.
- 같은 디시전은 한 번에 한 건을 진행하고, 완료 후 조건을 충족하면 다시 사용한다. 완료 후 별도 재사용 대기시간이나 자동 재실행을 추가하는 요구는 없다.
- 반복 횟수에 따라 정치력 비용·점유 공장 수·공사 기간·회당 자원 증가량을 올리지 않는다.
- 완료 횟수로 목록에서 숨기는 상한을 두지 않는다. 원본의 5회 제한과 기간 증가를 그대로 가져오지 않는다.
- 한 사업을 정상 완료한 횟수가 N이면 **이 사업 자체의 기본 자원 증가분은 +9 × N**이다. 1회 +9, 5회 +45, 6회 +54이며 6회째에도 계속 사용할 수 있어야 한다.
- 증가분은 자원 비축이나 공장·조선소 건설 보상이 아니라 해당 주의 자원 생산 기반이다. 최종 채굴량·수출량·국내 가용량은 기술·국민정신·무역 등 별도 조건의 영향을 받으므로 +9와 화면 최종 증가량을 동일시하지 않는다.

> 포항제철의 설립으로 우리 손으로 철강을 생산할 기반을 마련했습니다. 이제 늘어나는 산업 수요에 맞춰 용광로와 제강·압연 설비를 증설하고, 원료를 내리는 부두와 운송망을 함께 정비해야 합니다. 포항의 생산 능력을 확충하여 공장과 조선소에 필요한 철강을 안정적으로 공급하겠습니다.
>
> 「포항제철」 중점 완료와 건설 II 연구가 필요합니다. 정치력 25를 소비하고 민간공장 9개를 90일 동안 사용하여 경상의 기본 강철 생산량을 영구적으로 9 늘립니다. 완료 후 같은 비용과 기간으로 횟수 제한 없이 반복할 수 있습니다. 공사 중 경상의 소유권이나 완전한 통제권을 잃거나 항복하면 사업은 취소되며, 자원 보상과 정치력 환급은 없습니다.

정치력·민공·영토·비항복의 정확한 충족 여부는 기존 자동 조건 툴팁에서도 표시하는 설계다. 중점 효과의 해금 안내는 이름을 알리는 용도이며 별도 착수 조건을 면제하지 않는다.

### 향후 구현 시 대상과 확인할 항목 — 미실행

향후 구현이 별도로 승인되면 대상은 [디시전 정의](../common/decisions/HOK_KOR_resource_prospecting.txt), [한국 중점](../common/national_focus/korea.txt), [한국어 현지화](../localisation/korean/HOK_KOR_resource_prospecting_l_korean.yml), [영문 헤더 현지화](../localisation/english/HOK_KOR_resource_prospecting_l_english.yml)다. 기존 ID와 중점 배치·선행 관계·강철 +25 등 다른 보상을 보존하고, 실제 적용 상태와 검증 결과를 본 명세 및 관련 기록에 갱신해야 한다. 이 목록은 이번 파일 수정이나 테스트를 승인하지 않는다.

1. 나머지 조건이 같을 때 「포항제철」 미완료는 표시되지만 착수 불가, 완료는 착수 가능인지 확인한다. 중점 완료 후에도 건설 II·정치력·가용 민공·영토·비항복의 별도 조건이 작동해야 한다.
2. 중점 효과에 개별 디시전 해금 이름이 표시되고, 기존 강철 +25 보상이 유지되는지 확인한다. 범주 전체 해금이나 즉시 무료 실행으로 오해할 안내가 없어야 한다.
3. 두 현지화 파일의 동일 본문·BOM·헤더를 보존하고 실제 UI에서 새 설명문과 중점 완료 조건 툴팁을 확인한다.
4. 기존 회당 비용·90일·강철 +9·반복·취소 및 강원 사업이 유지되는지 변경 위험에 맞춰 확인한다. 기존 저장에서 진행 중인 사업의 처리와 변경 전 저장 호환성은 별도 확인 전까지 보증하지 않는다.

위 항목은 **향후 확인 계획이며 이번에 실행하지 않았다**. [기존 구현·검증 기록](incidents/2026-11-06-korean-repeatable-resource-prospecting.md)의 여섯 회 완료·재사용·저장 재로드 결과를 새 중점 조건이나 새 설명문의 검증으로 전용하지 않는다. 이번 문서화에서는 테스트·진단 파일이나 외부 작업 디렉터리도 새로 만들지 않았다.

## 11. 2026-11-07 포항 중점 연계 구현

사용자가 10절의 구현 설명을 인용해 구현을 요청한 뒤, 포항 디시전의 착수 조건·포항제철 중점의 개별 디시전 해금 안내·한국어/영문 헤더 설명문을 적용했다. 기존 강철 +25 중점 보상, 회당 정치력 25·민공 9개·90일·강철 +9, 반복·취소·AI 및 강원 사업은 보존했다.

독립 소스 검토는 최초 적용 24개와 게임 표시 보정 후 최종 적용 26개가 각각 실패 0개였다. 두 검토와 초기·최종 소스 해시는 새 외부 작업 루트 `C:\hoi\test\hok-pohang-focus-gate-20261107-01\`에 분리 보존한다. 이 경로는 중점 연계 전 자료가 있는 `C:\hoi\test\hok-resource-prospecting-20261106-01\`를 대체하거나 덮어쓰지 않는다.

실제 초기 UI에서 설명문의 모서리 괄호가 물음표로 표시되어 게임용 본문은 중점 이름을 `§Y포항제철§!`로 강조하도록 보정했다. 10절의 읽기용 문안은 보존한다. 중점 효과의 표준 해금 안내·기존 강철 +25, 중점 미완료만 차단되는 상태와 강제 완료 후 허용되는 상태, 실제 포항 디시전 클릭의 정치력 25 차감·90일 표시를 관측했다. 이 확인은 시험용 연구·정치력·민공 준비와 강제 중점 완료를 사용했으며 정상 캠페인 중점 진행을 입증하지 않는다.

같은 시험에서 실제 포항 디시전을 두 차례 실행해 매회 90일·정치력25·민공9 점유와 반환, 저장의 경상 기본 강철 **25→34→43**을 확인했다. 외부 fixture를 뺀 원래 두 모드의 완전 재시작은 체크섬 **0f96**, DLC36이었고 최종 설명문·미완료 조건 표시를 확인했다. 시험 게임 종료, 설정4개·모드 선택 복구, 기존 저장34개 보존과 Steam 플레이 복귀도 확인했다.

실제 결과와 한계·증거 위치는 [이번 구현·검증 기록](incidents/2026-11-07-pohang-focus-gate.md)을 따른다. 정상 연구·중점 경로 진행, 기존 저장 호환, 취소 재실행, 다른 DLC·장기 AI·멀티플레이를 이번 결과로 보증하지 않는다. 이전 여섯 회 완료 결과를 이번 새 중점 조건의 검증으로 취급하지 않는다.

## 12. 2026-11-07 강원·포항 설명문 간소화
